# 4. 環境の多様性と動的変化

## 現状の問題

現在のマップは均一かつ静的である。

- **資源ノードの均等配置**: Ore（左半分）とCrystal（右半分）がグリッド状に配置
- **資源の即時再生**: 毎tick全ノードがリセットされる
- **環境変化なし**: マップは初期状態から変わらない
- **地形の概念なし**: 全タイルが等価

均一な環境では、単一の「最適戦略」が存在しやすく、多様性が維持されない。
これは「競争排除則」として生態学で知られている：同一ニッチでは1種しか生存できない。

## 不足している仕様

1. **空間的な環境の不均一性**（ニッチの存在）
2. **時間的な環境の変化**（環境変動による適応圧の変化）
3. **地形・障害物**（空間戦略の多様化）

## 提案

### 4-1. 資源分布の不均一化

均等配置を廃止し、資源の偏在を導入する。

```
例:
- 「鉱脈」: Oreが密集する領域
- 「結晶洞」: Crystalが密集する領域
- 「砂漠」: 資源のない領域
- ノードごとに品質（maxCapacity, regenRate）が異なる
```

**効果**:
- 豊かな場所をめぐる競争が発生
- 「劣悪な環境に適応する」という別の生存戦略が生まれる
- 移動パターンの多様化（探索 vs 定住）

### 4-2. 環境の時間変化

**季節変動**: 一定周期で資源の再生速度が変化する

```
例: 1000tick周期
  tick 0-500:    Ore regenRate ×2,  Crystal regenRate ×0.5
  tick 500-1000: Ore regenRate ×0.5, Crystal regenRate ×2
```

**効果**:
- 特定資源に特化した戦略が不安定になり、汎用性が有利になる場面が生まれる
- 「季節に応じた行動切り替え」が進化しうる

**ランダムイベント**: 低確率で局所的な環境変化が起こる

```
例:
- 資源ノードの消滅/出現
- 局所的な「災害」（範囲内の耐久度減少）
```

**効果**:
- 予測不能な変化への頑健性が淘汰に寄与する
- 特定の環境に過適応した個体が淘汰される

### 4-3. 地形

タイルに属性を持たせ、移動や行動に影響を与える。

```
TileType:
  - Plain: 通常（現行と同じ）
  - Wall: 移動不可（障害物）
  - Rough: 移動コスト2倍
```

**効果**:
- 空間的な戦略（通路の封鎖、安全地帯の確保）が生まれる
- ただし現在のActionセット（上下左右移動のみ）では効果が限定的

## 優先度

1. **資源分布の不均一化**（高）: 最小の仕様変更で最大の多様性効果。資源有限化（02参照）と組み合わせることで相乗効果
2. **環境の時間変化**（中）: 過適応の防止に有効だが、パラメータ調整が難しい
3. **地形**（低）: 効果はあるが、他の不足点の方が優先度が高い
