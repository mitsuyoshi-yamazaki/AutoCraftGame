## プログラムのロバスト性

- 人間がプログラム可能で高度な情報処理を実行可能なことと、進化が可能なことを両方させる
- 課題：
  - このふたつの目的が両立困難であること
- 解決案A：制御装置の分割
  - 単体で動作可能で、組み換えや変異が起きても完全に壊れない、単純機能な制御コンポーネントを追加する
    - イメージとしては論理ゲート（閾値など設定は変えられる）
    - そのような低機能コンポーネントの組み合わせだけで自己複製や進化が可能か？
  - プロセッサは生産コスト、維持コストを大幅に増やし、「制御コンポーネントの組み合わせで作成するよりは遥かに安価だが、他コンポーネントより遥かに高価」というバランスにする
  - つまり、目指すのは以下の状況
    - ゲーム性：
      - プレイヤー（人間）は以下の順序でゲームにオンボードする
        - 単純機能のキャラクターを作る
          - 機能：オブジェクトを探してそこへ移動する
          - 想定される結末：代謝や自己修復ができずに死ぬ
        - 一定期間の生存が可能なキャラクターを作る
          - 機能：エネルギーノードでエネルギーを回収する
          - 想定される結末：代謝はできるが寿命で死ぬ
        - クラフト可能なキャラクターを作る
          - 機能：資源ノードで資源を回収し、加工する
          - 想定される結末：代謝はできるが寿命で死ぬ（ひとつ前と同じ）
        - コンポーネントをクラフト可能なキャラクターを作る
          - 機能：加工した資源を使ってコンポーネントをクラフト、世界へ放出する
          - 想定される結末：
            - 世界に対して影響を与えることができる（コンポーネントの放出）
            - 自身は代謝はできるが寿命で死ぬ（ひとつ前と同じ）
        - コンポーネントの集合をクラフト可能なキャラクターを作る
          - 機能：コンポーネントの組み合わせを調整することで、任意の機能を持つコンポーネント群をクラフト、世界へ放出する
          - 想定される結末：
            - （単純動作だが）自律動作するコンポーネント群を作成できる
            - 自身は代謝はできるが寿命で死ぬ（ひとつ前と同じ）
        - 自己複製できるキャラクターを作る
          - 機能：自身と同じ構成のコンポーネントの集合をクラフトする
          - 想定される結末：外的要因で死亡しなければ、自己複製して増殖していく
        - （プロセッサを含む）高次コンポーネントをクラフトできる
          - 機能：TBD
          - 想定される結末：高次コンポーネントをクラフトできる
        - プロセッサにより高度な制御・行動を実現できる
          - 機能：TBD
          - 想定される結末：プロセッサにより高度な制御・行動を実現できる
        - プロセッサを含む自己複製
          - 機能：TBD
          - 想定される結末：プロセッサを含む自己複製
        - プロセッサで実行するプログラムを変異させて自己複製
          - 機能：TBD
          - 想定される結末：進化
