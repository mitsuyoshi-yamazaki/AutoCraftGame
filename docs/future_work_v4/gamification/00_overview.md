# ゲーミフィケーション分析 — 概要

## 本文書の目的

v4アプリケーションを以下のゲーム体験として成立させるために、解決すべき課題と達成すべきマイルストーンを整理する。

### 想定するゲーム体験

サーバーで常時動作する巨大なフィールドに数万のキャラクターが活動する。プレイヤーは自分がデザイン・プログラムした「祖先種」を投入し、その活動・生殖・闘争・進化をクライアントアプリケーションから観察する。

### ゲームが果たす役割

このゲームは人工生命シミュレータの最終目標——「進化手法をゲームシステムとして提供せず、キャラクターの自律的な活動の結果として進化が創発する」——を達成するための手段である。人間同士の競争（より適応した祖先種のプログラミング）が、open-endedなシステムである「人間」からゲームへ多様性を常に投入する構造を持つ。

### 達成すべき2つの条件

| 条件 | 意味 | なぜ必要か |
|------|------|-----------|
| **面白い体験の提供** | プレイヤーが継続的に遊びたいと思うこと | プレイヤーがいなければ祖先種の投入が止まる |
| **多様な祖先種の獲得** | プレイヤーが異なる戦略の祖先種を設計すること | 単一戦略しかなければ進化の探索空間が狭い |

この2条件は相互依存する。多様な祖先種が投入されるほど生態系は複雑になり、観察が面白くなる。面白ければプレイヤーは新しい戦略を試す動機を持つ。
