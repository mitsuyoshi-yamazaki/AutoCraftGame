# AutoCraft v9 視覚言語の具体値

**日付**: 2026-09-22 ／ **対象**: v9 観察GUI（`v9/ui/`）

この文書は、v9 のシミュレーション仕様（`v9/docs/specs/`、特に `00_world_objects.md` と
`src/sim/types.ts`）と併せて読めば、**同じ絵を再現できる**ことを目的とした値の一覧です。
考え方の説明は [2026-09-22-simulation-ui-kit-feedback.md](2026-09-22-simulation-ui-kit-feedback.md) に、
規約そのものは `simulation-ui-kit/CONVENTION.md` にあります。

すべての値は実装から吐き出したものです。**色は1つも手で選んでいません**——
処方と下記の調整項目から導出しています。

---

## 1. 処方と調整項目

### 1.1 処方（キットの `lib/recipes.js` へ渡す）

```js
{
  surface: '#14201a',              // 面の色。v9 の暗緑
  categorical: 'Paired',           // 原典の系列（ColorBrewer）
  sequentialPerceptual: 'viridis',
  diverging: 'PuOr',
  chromaScale: 0.95,               // 個体（主役）の彩度
}
```

### 1.2 処方の外の調整項目

| 項目 | 値 | 意味 |
|---|---|---|
| `environmentChroma` | 0.75 | 環境用パレットの彩度。同じ処方を彩度だけ変えて2組導出する |
| `energyHue` | 95 | 予約色の黄の色相（OKLCh） |
| `energyChroma` | 0.90 | その明度で出せる彩度上限に対する比 |
| `energyLightness` | 0.86 | 同・明度。**カテゴリ色の帯（0.74）を意図的に外している** |
| `energyBackdrop` | 0.55 | 湧出点の下敷き。黄を面の色へ寄せる度合い |
| `structureLightness` | 0.55 | 予約色・無彩色（明）の明度 |
| `wasteLightness` | 0.40 | 予約色・無彩色（暗）の明度 |
| `cornerPx` | 1.5 | 菱形の角丸が辺を食う長さ（px）。マークの大きさに依らず一定 |

## 2. 色

### 2.1 面のトークン（キットが処方から導出）

| トークン | 値 | 明度 | 面との比 | 用途 |
|---|---|---|---|---|
| `base` | `#14201a` | 0.23 | — | キャンバスの地、ページの背景 |
| `panel` | `#1f2b25` | 0.28 | 1.14 | 制御バー・側パネル |
| `line` | `#313e37` | 0.35 | 1.50 | 罫線、ワールドの境界 |
| `ink` | `#9daca4` | 0.73 | 7.09 | 文字。**マークには使わない** |
| `inkDim` | `#5c6a63` | 0.51 | 2.95 | 補助的な文字 |

### 2.2 予約色（他のクラスへは割り当てない）

明度・彩度・色相から直接導出します。**処方の系列や彩度を変えても動きません。**

| 色 | 値 | 明度 | 面との比 | 導出 |
|---|---|---|---|---|
| エネルギーの黄 | `#f2cf3d` | 0.86 | 11.00 | `lch(0.86, maxChroma(0.86,95)*0.90, 95)` |
| 湧出点の下敷き | `#6f6931` | 0.51 | 2.99 | 黄と面の色を OKLab で 0.55 混合 |
| 無彩色・明 | `#6d746e` | 0.55 | 3.50 | `lch(0.55, 0.012, 150)` |
| 無彩色・暗 | `#434a44` | 0.40 | 1.84 | `lch(0.40, 0.012, 150)` |

無彩色にわずかな彩度（0.012）と色相（150＝面の色相寄り）を残しているのは、
完全な無彩色だと面から浮いて見えるためです。

**無彩色・暗は面とのコントラストが 1.84 で、規約 A-4 の下限 3:1 を下回ります。**
廃棄系は最も豊富で最も情報量が少ないので、意図的に後ろへ下げています。

### 2.3 割り当て可能な色

導出したカテゴリ色から、予約色すべてから ΔE 15 未満のものを機械的に外した残りです。

| パレット | 彩度 | 導出された色 | 割り当て可能 | 除外 |
|---|---|---|---|---|
| 個体用 | 0.95 | 5色 | `cat0`〜`cat3` = `#1fa2d5` `#b16dfa` `#32e727` `#fb4f5b` | `#fcaf3f`（黄に近い） |
| 環境用 | 0.75 | 5色 | `cat0`〜`cat3` = `#4aa0c8` `#aa79e5` `#65e15c` `#e8656a` | `#f0b465`（黄に近い） |

## 3. 形

キットの形族4種に、v9 固有の1種を足しています。**すべて面積を単位円（π）へ揃えて**
から半径を掛けるので、面積係数が同じなら見かけの大きさも揃います。

| 形 | 生成器の引数 | 面積合わせ | 用途 |
|---|---|---|---|
| `circle` | m=0 | ×1.0000 | 個体 |
| `square` | m=4, n=4.6 | ×0.9129 | エネルギー |
| `capsule` | m=4, n=8, sx=1.55, sy=0.6 | ×0.9291 | 単独部品 |
| `diamondStraight` | **点列**（m=4 と宣言） | ×1.2533 | 物質 |
| `diamond` | m=4, n=1.25 | ×1.1377 | 未使用（キット標準。辺が曲がるので不採用） |

### 3.1 `diamondStraight` の作り方

頂点 `(1,0) (0,1) (-1,0) (0,-1)` を直線で結び、**角だけを2次ベジエで丸めます**。
角と角の間には点を置かないので、描画側の `lineTo` がそのまま直線の辺になります。

角丸の食い込み比は、**マークの大きさから逆算**します（角丸は形ではなく仕上げなので、
データ量に連動させない）。

```
食い込み比 = min(0.35, cornerPx / (√2 × 1.2533 × 半径px))
```

`√2 × 1.2533 ≒ 1.772` は面積合わせ込みの単位菱形の一辺の長さです。
`cornerPx = 1.5` のとき、半径 3〜60px の全域で食い込みは 1.50〜1.54px に揃います。

**面積合わせは角を丸めない菱形の値（×1.2533）で固定します。** 角丸の比は大きさで変わるので、
輪郭から面積を計算し直すと面積合わせが大きさで動いてしまいます（半径 2.6px で ×1.3011、
60px で ×1.2534）。**面積はシミュレーション上の量の表現であり、角丸は表現上の装飾**なので、
装飾で量の表示が動いてはいけません。結果として、角を丸めたぶんだけ実面積は目標（π）を
わずかに下回りますが、量の表現としては正しくなります。

## 4. 大きさ

### 4.1 式

```
半径（世界単位） = 0.9 × √(量 / 量の基準) × √(面積係数)
半径（px）       = max(最小px, 半径（世界単位） × ズーム倍率)
```

`0.9` は量が基準と等しいときの半径（世界単位）です。**面積が量に比例します**
（規約 A-1。半径に比例させると2倍が4倍に見えるため）。

### 4.2 大分類ごとの係数

| 大分類 | 形 | 面積係数 | 最小px | 量の基準 | 量に使う値 |
|---|---|:---:|:---:|---|---|
| 個体 | 円 | **1.8** | 2.2 | `4`（部品数） | `group.memberIds.length` |
| 物質 | 菱形 | 0.7 | **2.6** | **`params.nodeAmountByAbundance.abundant`** | ノードは `remaining`、地面の物体は `count` |
| 単独部品 | 横長 | 0.45 | 1.0 | `1` | 常に 1（部品1個） |
| エネルギー | 四角 | 0.2 | 1.2 | `0.5` | 湧出点は常に 1、散布は `amount / params.energyCapacity` |

**物質の基準を定数で書いてはいけません。** v9 の資源ノードの初期量は実験ごとに
100倍違います（既定 400／移動複製 4000／潤沢 40000）。`abundant` の初期量を基準に取ると
「満量の abundant ノード＝つねに同じ大きさ」になります。

**エネルギー湧出点は量を持ちません**（総量無限・毎tick流量制限）。固定サイズです。

### 4.3 実際に画面に出る大きさ

移動複製種（`nodeAmountByAbundance.abundant = 4000`）を全体表示したとき
（ズーム約 8.28 px/世界単位）の実測です。

| 対象 | 量 | 半径 |
|---|---|---|
| 個体（6部品） | 6 | 12.2px |
| 廃棄系ノード | 4000 | 6.2px |
| 構造系ノード | 1964〜4000 | 4.4〜6.2px |
| エネルギー湧出点 | — | 4.7px |
| 活性系・伝達系ノード | 1000 | 3.1px |
| 情報系・触媒系ノード | 200 | **2.6px（最小に張り付き）** |
| 地面の物体 | 1〜20 | 2.6px（同上） |

最小 2.6px は量にすると約 696 相当です（基準 4000 のとき）。**下限に当たっている対象は、
量が減っても大きさが変わりません**——希少資源の枯渇は大きさでは読めず、
クリックして残量を見ることになります。これは意図した誇張です（規約 B-3）。

## 6. 状態

identity（形と色相）が使っていないチャネルにだけ載せます。
**状態のために形・色相を変えない。回さない。**

### 6.1 割り当て

| 状態 | チャネル | 対象 | 正規化 |
|---|---|---|---|
| 平均耐久 | 外周の弧 | 個体 | 生存部品の `durability` の平均 ÷ `params.maxDurability` |
| 耐久 | 内側の塗りの高さ | 単独部品 | `durability` ÷ `params.maxDurability` |
| 稼働中の Processor 数 | 中心の点（0〜4） | 個体 | 生存部品のうち `componentType === 'Processor'` かつ `running` の個数 |
| 当tickの残流量 | 薄い同形へ重ねる面積 | エネルギー湧出点 | `(params.energyNodeFlow − flowUsed)` ÷ `params.energyNodeFlow` |
| 選択 | 縁の有無 | 全て | |

**物質には状態を載せません。** 残量は大きさが運んでいるので、塗りに載せると重複します。

外周の弧は**円のときしか描かれません**（円でない形の周りに弧を回すと輪郭が崩れるため、
キットの実装が自動的に飛ばす）。個体を円にしているのはこれと噛み合っています。

### 6.2 エネルギー湧出点の描き方

量を持たないので大きさでは何も運べません。

1. 固定サイズの四角を**下敷きの色**（`#6f6931`）で塗る
2. その上に、**半径 × √(残流量比)** の四角を黄（`#f2cf3d`）で塗る

半径を平方根で縮めるので**面積が残流量の比に一致**します。満量なら下敷きが隠れて、
ふつうの黄の四角に見えます。

### 6.3 キットが使う寸法（半径に対する比）

| 要素 | 太さ・大きさ |
|---|---|
| 外周の弧 | 線幅 `半径×0.16`、半径 `半径×(1+0.10+0.08)` |
| 内側の塗り | 形でくり抜き、不透明度 0.55 |
| 中心の点 | 半径 `半径×0.12`、間隔 `半径×0.42`、横並び |
| 縁 | 線幅 `半径×0.17`、`半径×1.14` の位置 |

## 7. 描画の手順

1. キャンバス全体を `base` で塗る
2. ワールドの境界を `line` で 1px の矩形として描く
3. **個体以外**を描く
4. **個体を最後に描く**（重なったときに主体が隠れないようにするため）

各マークを描く前に、**地の色で輪郭を線幅 2px（= 隙間 1px × 2）でなぞってから**
本体を塗ります。隣り合う面の間に地の隙間ができ、重なりが読めるようになります（規約 B-4）。
規約の既定は 2px ですが、v9 はマークが小さい（資源で 3〜6px）ので 1px にしています。

クリック選択の許容半径は `4 / ズーム倍率 + 1.5`（世界単位）です。

## 8. 画面に出す宣言

規約 A-5（強いルール）に従い、**何をどのチャネルで運んでいるか**を側パネルに出します。
凡例も符号化表も `ui/visual-language-model.js` から生成しているので、実装と乖離しません。

| チャネル | 運んでいるもの |
|---|---|
| 形 | 大分類（物質・個体・単独部品・エネルギー） |
| 色相 | 種別。黄はエネルギー専用、2段の無彩色は構造系と廃棄系の専用 |
| 大きさ | 量（面積に比例）。ただし下限あり。エネルギー湧出点は量を持たないので固定 |
| 位置 | 場所（ワールド座標） |
| 長さ | 耐久（個体は外周の弧、単独部品は内側の塗りの高さ） |
| 明度 | 豊富な物質の区別（構造系＝明・廃棄系＝暗の2段） |

## 9. 既知の逸脱

| 逸脱 | 条項 | 理由 |
|---|---|---|
| 廃棄系の面とのコントラストが 1.84（下限 3:1） | A-4 | 最も豊富で最も情報量が少ないものを意図的に後ろへ下げている |
| 物質の大きさに下限があり、下限では量が読めない | A-1 | 希少資源が点に潰れて存在すら読めなくなるため（B-3 が許容する誇張） |
| エネルギーの黄が明度帯（0.74）を外れて 0.86 | B-2 | 1クラス専用の予約色なので、明度を使っても群が混ざらない |
| 色覚多様性を考慮していない | A-2 | プロトタイプのため範囲外と決定。通常視の色差だけで検査している |
