# GUI 要件定義

## 目的

CLIベースのシミュレーションを2Dビジュアルで表示し、人間がイベントの発生や状況をリアルタイムに把握できるようにする。

## 機能要件

### FR-1: 2Dマップ表示

- 20×20グリッドをCanvas上にセル単位で描画する
- ResourceNode（OreNode / CrystalNode）をセル色で区別表示する
- ResourceNodeのremaining量に応じて濃淡を変える（残量が少ないほど薄い）
- EnergyNodeをセル上に表示する（stored量に応じて濃淡を変える）
- Remains（残骸）をセル上に表示する
- キャラクターをセル上にアイコンで表示する（アクティブ / 非アクティブを色で区別）

### FR-2: キャラクター情報表示

- キャラクターをクリックすると詳細パネルに情報を表示する
  - ID、位置、耐久値、エネルギー、コンポーネント一覧、インベントリ、現在のアクション

### FR-3: イベントログ

- character_spawned / character_died イベントをリアルタイムにログ表示する
- 各イベントにtick番号を付与する
- スクロール可能な領域に表示する

### FR-4: シミュレーション速度制御

- tick/s（1秒あたりのtick数）を設定できる
- UI上のボタンまたはスライダーで変更する
- 範囲: 1〜60 tick/s

### FR-5: 一時停止 / 再開

- ボタンクリックで一時停止 / 再開を切り替える
- スペースキーでもトグルできる

### FR-6: 統計情報表示

- 現在のtick番号
- 生存キャラクター数
- 累計誕生数 / 死亡数
- 残存ResourceNode数
- EnergyNode総stored量

### FR-7: Storybook（描画要素カタログ）

- ゲーム中に描画する各要素をStorybookに個別表示する
- 各要素の状態バリエーションをストーリーとして一覧できるようにする
- 対象ストーリー:
  - ResourceNode: OreNode / CrystalNode、remaining量バリエーション
  - EnergyNode: stored量バリエーション
  - Remains: コンポーネント数・インベントリ量バリエーション
  - Character: アクティブ / 非アクティブ、耐久値段階、エネルギー段階、コンポーネント構成
  - GridOverview: 全要素を配置した一覧

## 非機能要件

- ブラウザ上で動作する（サーバー不要、Vite dev serverのみ）
- 既存のゲームロジック（src/）を変更しない
- pixi.js v8を描画エンジンとして使用する
- Storybook（@storybook/html-vite）で描画要素のカタログを提供する
