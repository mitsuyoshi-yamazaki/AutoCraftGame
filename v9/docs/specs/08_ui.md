# GUI（観察アプリ）仕様

ヘッドレスCLIに加え、実験結果をブラウザで視覚的に観察するGUIを提供する。
過去バージョン（v3/v8）のUIと同じ流儀（vite + canvas + 制御バー + 側パネル）だが、
描画は依存を増やさないため素のCanvas 2Dで実装する（v8はpixi.js）。

## 起動

```bash
npm run ui        # 開発サーバー（http://localhost:5173）
npm run build:ui  # 静的ビルド（dist/）
```

## 構成

| ファイル | 役割 |
|---|---|
| `src/experiments.ts` | 実験レジストリ（名前付き実験のconfigとパラメータ）。GUIとCLIで共有 |
| `ui/index.html` | レイアウト（制御バー・キャンバス・側パネル・凡例） |
| `ui/renderer.ts` | Canvas 2Dレンダラ（ワールド描画・パン/ズーム・クリック選択） |
| `ui/main.ts` | メインループ（実験選択・再生/停止・速度・メトリクス・選択詳細） |
| `vite.config.ts` | root=ui、`@`→src のエイリアス |

## 実験の選択

`src/experiments.ts` の `EXPERIMENTS` に登録された実験をドロップダウンで選ぶ。各実験は
初期状態config（seedから生成）と専用パラメータ（例: 移動種は資源密度の高い環境）を持つ。
登録済み: 祖先種の自己複製 / 変異 / 自己拡張 / 自己修復 / 捕食 / 移動複製 / 空間競争。

## 描画

- **資源**: MatterNodeは物質カテゴリ別の色（構造=灰青、活性=赤、伝達=水色、情報=金、触媒=紫、
  不純物=茶）で残量に応じた大きさ。EnergyNodeは黄。地面の散布物は暗い小円
- **個体**: グループは1つの円で描き、構成から推定した「種」で色分けする
  （Disassemblerを持つ=捕食者/赤、Actuatorを持つ=移動種/水色、Harvesterのみ=定住種/橙）。
  大きさは部品数に比例。残骸のみの個体は灰。単独コンポーネントは種別色の小円
- **操作**: ドラッグでパン、ホイールでズーム、クリックで最寄りオブジェクトを選択

## 制御とメトリクス

- 制御: 実験選択・seed入力・リセット・再生/停止（Space）・1tickステップ・速度（tick/s）・フィット
- メトリクス: tick、種別の個体数、グループ数、移動種の拡散距離、誕生/死亡累計、
  コンポーネント種別数、資源ノード数、原子総量（保存確認）、蓄積エネルギー
- 選択詳細: 個体（構成部品・耐久・稼働状態）、資源ノード（残量）等

## 実装との関係

- GUIは `src/sim/` のシミュレーション本体をそのまま駆動する（`executeTick`/`buildInitialWorld`）。
  乱数はシード付きPRNGを保持し、決定論はCLIと同一（同一実験・同一seedで同じ展開）
- GUIはシミュレーション仕様を一切変更しない。観察のための表示層である
