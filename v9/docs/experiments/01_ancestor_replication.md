# 実験01: 祖先種の自己複製と意図的変異

## 目的

プロジェクトの核心実験（v1〜v8を通じて未実施）:

1. **R1**: 4コンポーネント構成の祖先種が、クラフトツリーを経由する完全な自己複製を行えること
2. **R2×R6**: システムが変異手法を一切提供しない世界で、**プログラム自身が実装した変異**が
   複製時に発現すること

## セットアップ

- 祖先種: Processor + Assembler + Storage + Harvester（チェーン接続、初期エネルギー1000）
- クレードル配置: 半径1.5に自然産出7物質のMatterNode＋EnergyNode各1
- プログラム: [src/programs/ancestor.ts](../../src/programs/ancestor.ts)（ProgramBuilderによる手書きアセンブリ）
  - 構成: 起動時CSCAN → 材料表駆動の選択回収 → 工程表駆動のクラフト15種18回 →
    子4部品の組立（子Storage自由設置→子Assembler/Harvester/Processorを接続）→
    エネルギー800＋余剰材料の転送 → 自pmem1024語の複写 → run_flag起動 → ループ
  - **実測サイズ: コード約620語＋表・グローバル（pmem 1024語に収まる。机上見積り370語の1.7倍）**
- 変異版: 複製のたびにプログラム内実装のLCG（seed=起動tickでXOR）でアドレスとビットを選び、
  子のコピーにのみXORで1ビット反転を注入（親は無傷）
- 実行: `npm run sim -- --ancestor [--ancestor-mutate] --ticks N --seed S`

## 結果

### 複製サイクル（seed=42）

| 事象 | tick |
|------|------|
| 子1完成・起動（∠0°） | 約400 |
| 子2完成・起動（∠60°） | 約900 |
| 子3完成・起動（∠120°） | 約1400 |

- **複製1サイクル ≈ 400〜500 tick**（机上見積り500〜800の下限側）
- 親は(50,50)から動かず、子は周囲60°刻みのリングに配置される

### 個体群動態（seed=42）

| tick | 稼働個体 | 残骸 | 地面の山 | 備考 |
|------|---------|------|---------|------|
| 3,000 | 7 | 0 | 0 | 指数増殖期。8体目建造中 |
| 10,000 | 2 | 5 | 14 | クレードルのInfoSeed枯渇→複製停止→耐久度死→残骸が自然崩壊し資源が地面へ還流 |

- 原子総量は全実行・全時点で初期値と完全一致（S:1814 B:205 A:202 I:44 T:201 C:41 X:400）
- **誕生 → 増殖 → 資源枯渇 → 老衰死 → 崩壊 → 資源還流** の完全な生態サイクルを初観察

### 変異の検証（テスト: test/ancestor.test.ts）

- 変異なし: 子のpmem（コード・表領域）は親と**ビット単位で完全一致**（コピー忠実性）
- 変異あり（gateMask=0で毎回変異）: 子のコピーは**ちょうど1語・1ビット**だけ親と異なる
- 変異を含めて決定論が完全に保たれる（同一シード2回で世界状態が一致）

## 実装過程で発見・修正した問題

| 問題 | 対策（仕様変更） |
|------|----------------|
| 出現直後の子部品（質量7）が親との重なり反発で1tickに約5.7ユニット射出され、接続射程(3.0)外へ飛ぶ | **MAX_SPEED=1.0** を導入（媒質の終端速度。01_physics.md） |
| 2体目の子部品が1体目の子個体の真上に出現し、衝突連鎖で親がクレードル圏外へ押し流される | **自由設置の方位を設置ごとに60°回転**（02_components.md）、SPAWN_OFFSET=2.0 |
| 工程順によっては材料収支が途中で負になる（R10のBaseSolid副産物をR7より先に使う必要） | プログラム側で工程表を修正（仕様変更なし。工程順序が生存に関わる=戦略空間の実在） |
| プログラムのレジスタ規約ミス（転送先lidがヘルパのスクラッチに上書きされ、子への送金が失敗） | プログラム側で修正＋ビルダに検査追加（子がエネルギー0で凍結する「先天疾患」として現れた） |

## 考察

1. **プロジェクト目的の中核が実証された**: 進化手法をシステムが提供しない世界で、
   人間（AI）が書いた約620語のプログラムが自己複製し、変異はそのプログラム自身の
   実装（LCG＋XOR）として発現した。変異アルゴリズムはプレイヤーが自由に書き換えられる
2. **淘汰圧が機能している**: 資源の有限性（InfoSeed枯渇）と耐久度（寿命約5,000tick）により、
   無限増殖は起きず、個体群は増殖→定常→衰退の動態を示した
3. **定住種の限界が進化の勾配になっている**: 子は親のクレードルの一部にしか届かず
   （移動能力がないため）、2世代目の複製は困難。**Actuator/Sensorの獲得に明確な適応価値がある**
4. 残骸の自然崩壊による資源還流が機能し、系は閉じている（原子保存則）
