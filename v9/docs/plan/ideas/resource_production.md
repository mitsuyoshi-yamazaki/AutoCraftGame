# 資源の産出方式

## 概要

クラフトツリーの検討の一環として、資源がどのような形式で産出されるかの方式を整理する。
現実の資源のメタファーを出発点にしつつ、対応する現実の資源がないものも含む。

## 提案済みの方式

### 1. 有限・一点集中

有限の資源が空間の一点にまとまっている。鉱物などのメタファー。

### 2. 無限・一様供給

無限の資源が（揺らぎはあるものの）一様に供給され続ける。日光や熱のメタファー。

### 3. 無限・固定領域

特定の一定の空間から無限の資源が取得できる。水源のメタファー。

## 追加で挙がった方式

### 4. 移動する資源

資源自体が空間内を移動する。群れ、漂流物のメタファー。
産出点が時間経過で移動するパターンも含む。

### 5. 時間変動する資源

周期的に産出量が増減する。潮汐、季節のメタファー。
一度に大量に出現し以後しばらく出ないパターン（噴火、隕石）も含む。

### 6. 条件依存で発生する資源

他の資源やオブジェクトが存在する場所にのみ産出される。触媒的。
個体の活動の副産物として発生するパターン（排泄物、死骸）も含む。v2の残骸がこれに近い。

### 7. 勾配を持つ資源

ある点から離れるほど濃度が下がる。拡散、熱源、ガス噴出口のメタファー。

### 8. 流れる資源

空間の一方向に流れている。川、風のメタファー。

### 9. 再生する資源

有限だが、時間経過で一定量まで回復する。森林、草原のメタファー。

## 分類軸

産出方式を分類する軸は以下の通り。

| 軸 | 選択肢 |
|---|---|
| 総量 | 有限 / 無限 |
| 空間分布 | 一点 / 一定領域 / 一様 / 勾配 / 移動 / 流れ |
| 時間挙動 | 定常 / 周期的 / 突発的 / 再生(上限あり) |
| 発生条件 | 無条件 / 他資源依存 / 個体活動依存 |
