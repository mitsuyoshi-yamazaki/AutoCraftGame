# クラフトツリー作成方針

## 全体の進め方

1. 原子セット（6〜10種）を具体的に定義する
2. 最下層15物質に原子構成を割り当てる
3. 基本レシピ（20〜30個）を設計し、循環を保証する
4. 中間物質（階層2〜3）を追加する
5. コンポーネント生成レシピを設計する
6. 全体バランスを調整する

## 原子設計の方針

- 各原子に役割（意味づけ）を持たせ、その原子を含む物質の性質の傾向を決める
- 原子構成と物質の機能の対応に単調性を持たせる（理解可能性のため）
- コンポーネントの機能と原子の役割が自然に対応するようにする

## 物質設計の方針

- 最下層物質の原子数は小さく（2〜6個程度）に抑える
- 役割ごとにクラスター化する（構造系/活性系/情報系など）
- 後の合成で「意味のある組み合わせ」が作れるように配置する
- 各原子が偏らず分布するようにする
- 中間物質の原子数は3〜8程度（低層よりやや増加）

## レシピ設計の方針

- すべてのレシピで原子保存を厳守する
- 役割別に分類する
  - 合成型（高次化）
  - 分解型（低次化）
  - 再配置型（構造変換）
- 各原子（全種類）に少なくとも1つの循環経路を確保する
- 不純物（X）は「蓄積するが回収可能」とする
- 複雑な合成ほど不純物（X）を生成するようにする

## 資源設計の方針

- 情報原子（I）を希少資源にする → 高度構造のボトルネック、ゲーム性の源泉
- 活性原子（A）を制御資源にする → 反応の鍵であり暴走の原因にもなる
- 不純物原子（X）を軽視しない → 必ず循環経路を作り、完全消滅させない

## 副産物の設計方針

- 「副産物」はレシピ上の通常の生成物として扱う（特別な区分なし）
- 副産物は「再利用しにくいが完全に無価値ではない」中間に置く
- 不要な物質から有用な物質を回収する淘汰圧となることを意図する
- 廃棄物処理レシピが後付けパッチ的に増殖しないよう、初期段階で原子ごとの循環経路を確保する

## 設計の認識

- クラフトツリー設計は「化学系」ではなく「保存付きグラフ設計問題」である
  - ノード: 物質
  - エッジ: レシピ
  - 制約: 原子保存
- いきなり50〜100物質を設計するのではなく、最初に「閉じた小系」を作る
  - 小系で循環とコンポーネント生成を成立させてから拡張する

## 安定性設計の方針

- 安定性は各物質の原子構成から導出される（スカラー値）
- 構造原子（S）が多いほど安定、活性原子（A）が多いほど不安定
- 自発変化は「より安定な物質へ」の方向に進む
- 温度が高いほど遷移確率が上がる
