# クラフトツリー要件

## 概要

自然界に産出する物質をクラフトしていくことにより、生物のコンポーネント（臓器や細胞内小器官のメタファー）を作成できるようにする。

コンポーネントは極度に抽象化された高度なオブジェクトであり、低次の物質から生産できるように、抽象化した かつ納得感のあるクラフトツリーを設定する。

## 物質と原子

- クラフトツリーに登場する物質は分子のレイヤーである
- 物質を構成する原子のレイヤーが存在し、原子種ごとに世界全体の総量が保存される
  - 物質の合成や分解を行っても、種類ごとの原子の総量が変わらないようにレシピを定義する
- ここで言う原子・分子・物質は現実世界のメタファーであり、全く同一の性質を持っていなくて良い
  - フィクションであるため、厳密に分子や原子のレイヤーが成立していなくとも良い

## エネルギーと熱

- エネルギーは物質とは別の要素であり、クラフトを含む各種アクションで消費される
- エネルギーは世界に無限に産する（系外からの入力: 太陽光のメタファー）
- エネルギーは消費時に熱に変わり、熱は散逸して最終的に世界から消える（系外への出力: 宇宙空間への放射のメタファー）
- エネルギーから物質への変換は不可

## クラフトツリーの規模

- 階層数: 3〜5階層（最も低次の物質からコンポーネントまで）
  - 人間が設計を把握できる限界として5階層程度を上限とする
- 最下層およびその上の階層の物質数: 15程度
- 全体の物質種類数: 50〜100程度
- 原子の種類数: 6〜10種程度

## コンポーネント

対象コンポーネント一覧（機能は名前の通り）:

- Assembler
- Disassembler
- Processor
- MemoryCore
- Actuator
- Sensor
- Storage

コンポーネントの性質:

- 純粋な物質であり、原子構成を持つ
- 特殊なアクションを行える点のみが通常物質と異なる
- 分解可能
- 劣化は最終的に導入するが、クラフトツリー設計段階では考慮不要
- 生成はレシピ方式（中間生成物およびエネルギーを投入して作成）

## レシピ

- すべてのレシピで原子収支が一致する（原子保存）
- 決定論的（確率的要素なし）
- 1レシピあたりの材料/生成物の最大数はおおよそ4（エネルギー・熱は計上せず）
  - ただし強い制約ではなく例外は許容する
- 触媒は入力と出力の両方に同一物質として現れる形で表現する

## コスト（副作用）

- 物質操作には基本的に副作用が伴う
  - 合成を促すエネルギーや熱の入力が必要
  - 目的物質の他に不要/有害な物質が副産物として生成されうる
- レシピ上、「副産物」という特別な区分はない（単なる生成物の一部）
- ポジティブなコスト: ある物質の分解時にエネルギーが生じる等（バッテリー的用途）
- ネガティブなコスト: エネルギーの消費、好ましくない副産物の生成、熱の増加

## 安定性と自発変化

- 物質には安定性パラメータがある
- クラフト/分解アクションによらず、より安定な状態へ自発的に遷移することがある
  - 温度の高い環境下では分解が進む
  - 触媒物質と隣接していると合成が進む
- 自発変化の速度スケールはAssembler/Disassemblerによる操作より一桁以上遅い
  - 雰囲気づくりとしての役割（主体的に関わらないと世界が変化しないのを防ぐ）
- 安定状態は、周囲の環境（エネルギー、熱の量、周囲の物質）によって複数とりうる
- 放置時に収束状態を規定するのは仕組み上当然（生物種を全て死滅させた現実世界と同様）

## 物質総量保存

- 物質の総量保存は、最もシンプルな淘汰圧を環境に与えるために必要
- 各原子種ごとに保存される（総和のみではなく種類別）
- すべての原子が循環可能であること（デッドエンドがないこと）

## 「それらしさ」の基準

- ゲーム/シミュレーションとして、ある程度それらしくなれば良い（例: 銅線とレジンで回路が作成できる等）
- コンポーネント仕様がナノマシンと生物の中間のようなものであるため、架空物質の方が良いと考えている
- 「それらしさ」の基準を定めること自体もクラフトツリー作成の目的のひとつ
