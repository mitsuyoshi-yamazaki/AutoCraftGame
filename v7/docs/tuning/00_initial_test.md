## 観察

### 成功した点
1. **Assembler が材料を回収し、コンポーネントを生産する一連の流れが動作**
2. **Processor (c/d) が空の Assembler にレシピ設定・トリガーを行う流れが動作**
3. **生産された Assembler がさらに生産を行う（第2世代以降）**

### 問題
1. **新規 Processor が起動されていない**: running Processor は初期の 40 のまま
   - 原因候補: c/d のプログラムで空 Processor を見つけてメモリコピー→起動する Phase 2 が動作していない
   - メモリコピー（1024ワード）に ~2 tick かかるが、その間にランダム移動で対象が離れている可能性
   - 要調査

2. **Materials が緩やかにしか消費されない**: 500 tick で 500 → 284。Assembler の absorptionPerTick=1 が遅い

## 修正: Processor 起動の問題

### 原因
instructionsPerTick=5000 では、メモリコピーループ（1024ワード × 4命令/ワード ≈ 4096命令）+ Phase 1/2 のオーバーヘッド（~200命令）が 1 tick に収まらなかった。tick をまたぐと I/O 状態（PMEM_TARGET_ID, PMEM_ADDR）がリセットされ、コピーが完了しない。

### 修正
instructionsPerTick を **10000** に変更。
