# 001: 近接維持なしでの自己複製サイクルの持続性

## 懸念

v7 では全オブジェクトがランダムに移動し、コンポーネント間の近接を維持する仕組みは設けない。自己複製サイクルが成立するには、以下の一連の近接イベントが全て発生する必要がある:

1. Assembler a が近接範囲内の材料を回収 → 空 Assembler e を生成
2. Assembler b が近接範囲内の材料を回収 → 空 Processor f を生成
3. Processor c が e を発見（近接範囲内）→ e にレシピを書き込む
4. Processor c が f を発見（近接範囲内）→ f にメモリをコピーし起動
5. Processor d が別の e, f に対して同様の操作を行う

全てのステップで「偶然の近接」が必要であり、ランダム移動によりコンポーネントが散らばると、これらのイベントが連鎖的に起きる確率が低下する。

## 影響

- 自己複製サイクルが 1 世代すら完了しない可能性がある
- 完了しても世代を重ねるごとにコンポーネント群が拡散し、サイクルが途切れる可能性がある
- パラメータ（マップサイズ、ランダム移動幅、近接距離、初期資源量）のチューニングが事実上の成否を決める

## 対応方針

- まず仕組みなしで実装し、動作させて問題の程度を確認する
- 問題が深刻な場合、以下の対策を検討する:
  - ランダム移動の幅を十分に小さくする
  - 近接距離を広げる
  - 初期コンポーネントを密集配置する
  - 将来的にコンポーネント間の接続機構（物理的な結合）を導入する

## ステータス

未検証。実装完了後に評価する。
