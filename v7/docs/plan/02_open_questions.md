# v7 未決定事項

本文書は v7 の設計過程で挙がった質問・決定事項のうち、未決定のものを管理する。

## 決定済み（アーカイブ）

以下の項目は議論を経て決定済み。詳細は `03_decided_specs.md` および `04_component_specs.md` を参照。

- 世界モデル（物体の種類、エネルギーの物理表現、資源発生、統一型）
- 移動（ランダム移動、衝突なし、向き固定）
- 近接（一律距離）
- コンポーネント種別（Assembler + Processor のみ）
- 操作メモリの構造（共通領域 + アクション固有領域）
- Assembler 仕様（レシピ、ASSEMBLE フロー、材料吸収）
- Processor 仕様（内蔵メモリ 1024 ワード、命令セット流用、CHECKPOINT 廃止）
- Processor 実行モデル（stopped/running、1000 命令/tick）
- I/O モデル（自身状態、操作メモリ、SCAN、外部操作メモリ R/W、外部 Processor メモリ R/W）
- レシピテーブル（Metal, Circuit, Assembler, Processor。ID 1〜4）
- 自己複製（近接維持なし、変異なし、自然変異のみ）
- 実装ベース（v6 コピー + vm/ui 流用 + src 大部分新規）

## 未決定事項

### パラメータ（実装後調整）

1. **レシピテーブルのエネルギーコスト** — 各レシピの生成に必要なエネルギー量
2. **レシピテーブルの組立時間** — 材料充足後の組立フェーズの tick 数
3. **ランダム移動の幅** — 1 tick あたりの移動距離の分布
4. **近接距離（proximity range）** — コンポーネント間の相互作用距離
5. **材料吸収速度** — Assembler が 1 tick に吸収できる材料/エネルギーの量
6. **初期状態の配置** — a〜d の数、配置密度、初期資源・エネルギー量

### 検証目標

7. **達成基準の定義** — v7 の世界モデルにおける「自己複製」の成功判定
8. **「個体」の定義** — キャラクター概念がない世界で、何をもって 1 つの自己複製単位とするか
