# GUI 要件定義 — v3

## 目的

CLIベースの連続空間シミュレーションを2Dビジュアルで表示し、人間がオブジェクトの移動、衝突、イベントの発生をリアルタイムに把握できるようにする。

## 機能要件

### FR-1: 2D連続空間マップ表示

- ワールド（width × height の連続矩形領域）をCanvas上に描画する
- ワールド境界（壁）を視覚的に表示する
- ResourceNode（OreNode / CrystalNode）を円で描画し、色で種別を区別する
  - remaining量に応じて濃淡を変える（残量が少ないほど薄い）
- EnergyNodeを円で描画する（stored量に応じて濃淡を変える）
- Remains（残骸）を円で描画する
- キャラクターを円で描画する（アクティブ / 非アクティブを色で区別）
- 全オブジェクトの衝突半径を視覚的に反映する（オブジェクトの描画サイズ ≈ 半径に基づく）
- キャラクターの速度・加速度ベクトルの描画は行わない

v2からの変更:
- グリッド（20×20セル）の概念が廃止され、連続空間上にオブジェクトが自由な座標で配置される
- セル単位の描画ではなく、各オブジェクトを独立した円として座標に基づいて描画する
- グリッド線は廃止する

### FR-2: オブジェクト情報表示

- マップ上のオブジェクトをクリックすると詳細パネルに情報を表示する
  - **Character**: ID、位置、質量、耐久値、エネルギー、コンポーネント一覧、インベントリ、現在のアクション
  - **ResourceNode**: type、位置、remaining
  - **EnergyNode**: 位置、stored / maxStored、productionRate
  - **Remains**: 位置、コンポーネント一覧、インベントリ

v2からの変更:
- 位置が浮動小数点数（小数点以下1桁表示を推奨）
- 質量の表示を追加

### FR-3: イベントログ

- character_spawned / character_died イベントをリアルタイムにログ表示する
- 各イベントにtick番号を付与する
- スクロール可能な領域に表示する

（v2と同一）

### FR-4: シミュレーション速度制御

- tick/s（1秒あたりのtick数）を設定できる
- UI上のボタンまたはスライダーで変更する
- 範囲: 1〜60 tick/s

（v2と同一）

### FR-5: 一時停止 / 再開

- ボタンクリックで一時停止 / 再開を切り替える
- スペースキーでもトグルできる

（v2と同一）

### FR-6: 統計情報表示

- 現在のtick番号
- 生存キャラクター数
- 累計誕生数 / 死亡数
- 残存ResourceNode数
- EnergyNode総stored量
- 残骸数
- 種族ごとの個体数（program.nameでグループ化）

（v2と同一）

### FR-7: Storybook（描画要素カタログ）

- ゲーム中に描画する各要素をStorybookに個別表示する
- 各要素の状態バリエーションをストーリーとして一覧できるようにする
- 対象ストーリー:
  - ResourceNode: OreNode / CrystalNode、remaining量バリエーション
  - EnergyNode: stored量バリエーション
  - Remains: コンポーネント数・インベントリ量バリエーション
  - Character: アクティブ / 非アクティブ、耐久値段階、エネルギー段階、コンポーネント構成
  - WorldOverview: 複数オブジェクトを配置した一覧（グリッドなし）

v2からの変更:
- GridOverview → WorldOverview（グリッドがないため名称変更）

## 非機能要件

- ブラウザ上で動作する（サーバー不要、Vite dev serverのみ）
- 既存のゲームロジック（src/）を変更しない
- pixi.js v8を描画エンジンとして使用する
- Storybook（@storybook/html-vite）で描画要素のカタログを提供する
