# セーブ/ロード機能 実装計画

## 概要

ゲーム状態をJSONファイルに保存し、ロードすることで同一状況を再現する機能を実装する。
前提として、ゲームパラメータ（定数・レシピ）を実行時に注入可能にするリファクタを行う。

## セーブファイル形式

```json
{
  "version": "3.10.0",
  "sessionStartedAt": "20260404_153012",
  "params": { ... GameParams ... },
  "world": { ... World state ... },
  "stats": {
    "totalBirths": 42,
    "totalDeaths": 35
  },
  "recentEvents": [
    { "tick": 100, "event": { "type": "character_spawned", ... } },
    ...
  ]
}
```

- `version`: 保存時の GAME_VERSION。ロード時にメジャー・マイナーが一致しなければ拒否
- `sessionStartedAt`: 大元の（tick=0 時点の）セッション開始日時
- `params`: 全ゲームパラメータ（後述）
- `world`: World オブジェクトそのまま（JSON シリアライズ可能）
- `stats`: 累計統計値（totalBirths, totalDeaths）
- `recentEvents`: 直近 n 件のイベント（n はUI設定、初期値10）。各エントリは tick 番号付き

## バージョン互換性チェック

ロード時、セーブファイルの version と現在の GAME_VERSION を比較:
- メジャーまたはマイナーが異なる → エラー（ロード拒否）
- パッチのみ異なる → 許容（ロード可能）

## セーブファイル命名規則

### 初期状態から実行されたゲームを保存する場合

```
{セッション開始日時}_{tick}.json
```

例: `20260404_153012_tick500.json`

### ロードした状態から再開されたゲームを保存する場合

```
{大元のセッション開始日時}_{ロード時のセッション開始日時}_{tick}.json
```

例: `20260404_153012_20260405_091500_tick750.json`

これにより、ファイル名から以下が判別できる:
- 大元のセッションが何か（最初のタイムスタンプ）
- 初期状態からの実行か、ロードからの再開か（タイムスタンプが1つか2つか）

### UIState への追加

```typescript
interface UIState {
  // ...既存フィールド...
  sessionStartedAt: string;   // 大元の（tick=0時点の）セッション開始日時
  resumedAt: string | null;   // ロードにより再開した場合のタイムスタンプ。初期実行なら null
}
```

## パラメータ化の範囲

### パラメータに含めるもの

「同一初期状態から同一の実行結果を再現するために必要な値」を基準とする。

**constants.ts から:**

| カテゴリ | パラメータ |
|---------|-----------|
| エネルギーコスト | NOOP, MOVE, HARVEST, RECHARGE, PROCESS, CRAFT, ASSEMBLE, WRITE, ACTIVATE, SENSE, REPAIR, DISASSEMBLE |
| 失敗ペナルティ | ACTION_FAILURE_COST_RATIO |
| 基礎代謝 | METABOLISM (コンポーネント別), INVENTORY_METABOLISM_PER_ITEM |
| エネルギー代謝 | ENERGY_METABOLISM_THRESHOLD, ENERGY_METABOLISM_SCALE |
| アクション値 | RECHARGE_AMOUNT, ASSEMBLE_ENERGY_TRANSFER, REPAIR_AMOUNT |
| 耐久 | FRAME_DURABILITY, DURABILITY_DECAY_NORMAL, DURABILITY_DECAY_STARVING |
| 物理 | MOVE_FORCE, FRICTION_COEFFICIENT, COLLISION_STIFFNESS, VELOCITY_CLAMP_THRESHOLD |
| 半径 | CHARACTER_RADIUS, RESOURCE_NODE_RADIUS, ENERGY_NODE_RADIUS, REMAINS_RADIUS |
| 距離 | INTERACT_RANGE, SPAWN_DISTANCE, SENSE_RANGE |
| レジスタ | REGISTERS_PER_COMPONENT |

**recipes.ts から:**

| カテゴリ | パラメータ |
|---------|-----------|
| レシピ | PROCESS_RECIPES, CRAFT_RECIPES |
| 質量 | RAW_MATERIAL_MASS, COMPONENT_MASS |

### パラメータに含めないもの

- UI定数: MIN_TPS, MAX_TPS, DEFAULT_TPS, DEFAULT_SEED
- 初期化定数: INITIAL_ENERGY, INITIAL_COUNT
- MIN_COMPONENTS（シミュレーション中は未使用。初期キャラクター構成のデフォルトのみ）
- WorldConfig（ワールド生成時のみ使用。World オブジェクト自体に幅/高さ/ノード情報が含まれる）
- 派生関数: getActionEnergyCost, getAssembleTotalCost, getFailurePenalty（パラメータから再計算）

## パラメータの引き回し方式: maker パターン

### GameParams 型定義

新規ファイル `src/params.ts` に定義:

```typescript
interface GameParams {
  // エネルギーコスト（アクション名 → コスト）
  readonly energyCosts: Readonly<Record<string, number>>;
  readonly actionFailureCostRatio: number;

  // 基礎代謝
  readonly metabolism: Readonly<Record<ComponentType, number>>;
  readonly inventoryMetabolismPerItem: number;
  readonly energyMetabolismThreshold: number;
  readonly energyMetabolismScale: number;

  // アクション値
  readonly rechargeAmount: number;
  readonly assembleEnergyTransfer: number;
  readonly repairAmount: number;

  // 耐久
  readonly frameDurability: number;
  readonly durabilityDecayNormal: number;
  readonly durabilityDecayStarving: number;

  // 物理
  readonly moveForce: number;
  readonly frictionCoefficient: number;
  readonly collisionStiffness: number;
  readonly velocityClampThreshold: number;

  // 半径
  readonly characterRadius: number;
  readonly resourceNodeRadius: number;
  readonly energyNodeRadius: number;
  readonly remainsRadius: number;

  // 距離
  readonly interactRange: number;
  readonly spawnDistance: number;
  readonly senseRange: number;

  // レジスタ
  readonly registersPerComponent: number;

  // レシピ
  readonly processRecipes: readonly ProcessRecipe[];
  readonly craftRecipes: readonly CraftRecipe[];

  // 質量
  readonly rawMaterialMass: Readonly<Record<string, number>>;
  readonly componentMass: Readonly<Record<ComponentType, number>>;
}
```

`DEFAULT_GAME_PARAMS` を現在の定数値から構築する。

### maker パターンの適用

各モジュールに factory 関数を追加し、パラメータをクロージャで閉じ込める。
パラメータ不要な純粋関数（hasItems, distance, isActive 等）はそのまま直接 export。

```
src/params.ts          GameParams 型 + DEFAULT_GAME_PARAMS
src/engine.ts (新規)   createEngine(params) → 全関数をバインドして返す
```

**モジュール別のリファクタ:**

| モジュール | 変更内容 |
|-----------|---------|
| constants.ts | 値の定義は残す（DEFAULT_GAME_PARAMS の素材として使用）。各モジュールからの直接 import は廃止 |
| recipes.ts | `createRecipeEngine(params)` → findProcessRecipe, findCraftRecipe, calculateMass, getItemMass を返す。パラメータ不要な関数 (hasItems, removeItems 等) はそのまま export |
| character.ts | `createCharacterEngine(params)` → createCharacter, createInactiveCharacter, applyBasalMetabolism, calculateBasalMetabolism, canPayMetabolism, decayDurability を返す。パラメータ不要な関数 (hasComponent, isActive, isDead, readRegister 等) はそのまま export |
| world.ts | `createWorldEngine(params)` → getObjectRadius, collidesWithAny, findNearest*, findSpawnPosition を返す。パラメータ不要な関数 (distance, updateCharacter 等) はそのまま export |
| physics.ts | `createPhysicsEngine(params, recipeEngine)` → computeFrictionForces, computeCollisionForces, integratePhysics を返す |
| program.ts | `createProgramEngine(params)` → evaluateProgram, findTargets, findNearestAngle を返す |
| actions.ts | `createActionEngine(params, deps)` → executeAction を返す。deps は他のエンジンから必要な関数群 |
| simulation.ts | `createSimulationEngine(params)` → executeTick, runSimulation を返す。内部で上記全エンジンを組み立てる |

**依存順序:**

```
recipeEngine     (params のみ)
    ↓
worldEngine      (params のみ)
    ↓
characterEngine  (params のみ — inventoryTotalCount は直接 import)
    ↓
physicsEngine    (params + recipeEngine.calculateMass + worldEngine.getObjectRadius)
    ↓
programEngine    (params のみ)
    ↓
actionEngine     (params + recipeEngine + worldEngine + characterEngine + programEngine)
    ↓
simulationEngine (全エンジンを統合)
```

### トップレベル API

```typescript
// src/engine.ts
export function createEngine(params: GameParams) {
  const recipeEngine = createRecipeEngine(params);
  const worldEngine = createWorldEngine(params);
  const characterEngine = createCharacterEngine(params);
  const physicsEngine = createPhysicsEngine(params, recipeEngine, worldEngine);
  const programEngine = createProgramEngine(params);
  const actionEngine = createActionEngine(params, { recipeEngine, worldEngine, characterEngine, programEngine });

  return {
    executeTick(world: World): TickResult { ... },
    runSimulation(world: World, ticks: number, onTick?): { ... },
    createCharacter: characterEngine.createCharacter,
    createInactiveCharacter: characterEngine.createInactiveCharacter,
    createWorld: (config: WorldConfig, rng: Rng) => ...,
    params,
  };
}
```

## セーブ/ロード実装

### 新規ファイル: src/save-load.ts

```typescript
interface SaveData {
  readonly version: string;
  readonly sessionStartedAt: string;
  readonly params: GameParams;
  readonly world: World;
  readonly stats: { totalBirths: number; totalDeaths: number };
  readonly recentEvents: readonly { tick: number; event: SimulationEvent }[];
}

function serialize(data: SaveData): string;
function deserialize(json: string): SaveData;  // バージョンチェック含む
```

## GUI 変更 (ui/main.ts)

### ボタン追加

コントロールバーに Save / Load ボタンを追加。

### 保存操作

1. Save ボタン押下
2. 現在の state から SaveData を構築
3. JSON 文字列化
4. Blob → URL → `<a>` click でダウンロードダイアログ表示
5. ファイル名の決定:
   - `state.resumedAt` が null → `{sessionStartedAt}_{tick}.json`
   - `state.resumedAt` が非null → `{sessionStartedAt}_{resumedAt}_{tick}.json`

### ロード操作

1. Load ボタン押下
2. `<input type="file" accept=".json">` でファイル選択ダイアログ表示
3. FileReader でファイル読み込み
4. deserialize でパース + バージョンチェック
5. バージョン非互換 → アラート表示して中断
6. 互換 → state を復元、エンジンをパラメータで再作成
7. `resumedAt` に現在日時を設定
8. レンダリング更新

## CLI 変更 (src/cli.ts)

### 新規オプション

```
--load <path>   セーブファイルをロードして実行を継続
```

- `--load` 指定時: ファイルからパラメータ + World を復元し、その状態から `--ticks` 分実行
- `--load` と `--program` は排他（同時指定でエラー）
- バージョン互換性チェックはGUIと同様
