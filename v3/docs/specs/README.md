# v3 仕様概要 — 連続空間物理モデルの導入

## バージョン目標

v2（離散空間・離散時間）のシミュレーション物理系を、**連続空間・離散時間**に変更する。

ゲームオブジェクトは連続値の座標を持ち、速度・加速度・衝突判定・摩擦などの物理的な仕組みが導入される。
これにより、キャラクターの移動は「隣のセルへの瞬間移動」ではなく「力を加えて加速し、慣性で移動する」動作に変わる。

## スコープ

### 導入するもの

- **連続座標系**: オブジェクトの位置が浮動小数点数の (x, y) で表現される
- **速度と慣性**: キャラクターが速度ベクトルを持ち、力の適用 → 加速 → 慣性移動する
- **質量**: キャラクターの構成から質量が決まり、加速度に影響する
- **摩擦**: 全キャラクターに一様な摩擦力（速度と逆方向）がかかり、無限加速を防ぐ
- **衝突判定**: オブジェクトに半径を持たせ、円同士の重なりで衝突を検出・応答する
- **ワールド境界**: 矩形の壁オブジェクトで世界を囲い、通常の衝突判定で境界を処理する
- **距離ベースのアクション**: 「隣接タイル」の概念を「一定距離内」に置換する
- **MOVEアクションの変更**: 方向指定を360度表現に変更し、力の適用として実行する

### 導入しないもの（v2を踏襲）

- 資源モデル（有限資源、総量保存）
- エネルギーモデル（生産、消費、散逸）
- レシピ体系（PROCESS, CRAFT）
- 基礎代謝の計算式
- 耐久度モデル（-1/tick, REPAIR）
- 死亡判定と残骸生成
- Program の Rule 構造（Condition/Action の形式）

### 導入しないもの（将来バージョン）

- v2スコープ外として定義されたものと同様（コンポーネント集合体モデル、Program変異機構など）

## v2からの主要変更一覧

| 領域 | v2 | v3 |
|------|-----|-----|
| 座標系 | 整数グリッド (20×20) | 連続浮動小数点 |
| 移動 | 1tick1セル、8方向、瞬間移動 | 力の適用 → 慣性移動 |
| 空間制約 | タイル占有（1タイル1オブジェクト） | 衝突判定（円の重なり → 反発力） |
| 隣接判定 | チェビシェフ距離、8近傍 | ユークリッド距離、距離閾値 |
| 方向指定 | 8方向離散値 | 360度連続値 |
| 境界 | `isInBounds` によるグリッド範囲チェック | 壁オブジェクトによる衝突 |
| SENSE | 方向 + 距離（チェビシェフ） | 相対座標 (x, y) |
