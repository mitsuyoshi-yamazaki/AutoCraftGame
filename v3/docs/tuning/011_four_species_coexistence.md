# 011: 4種族以上の長期共存パラメータ探索

日付: 2026-04-05

## 目的

「長期間（5000〜10000 ticks以上）にわたって、自己複製を行う4以上の種族が生存し続けること」を目標とし、ゲーム仕様を変更せずにパラメータ・初期条件の組み合わせを探索する。

## 判定基準

tick 10,000 時点で **人口≥2の種族が4以上** かつ **直近1000tickのbirths>0**

「人口≥2」としたのは、人口1の種族は自己複製しておらず REPAIR で生存しているだけの個体である可能性が高いため。

## 探索戦略

### 構造的分析

009 Exp12（現在のデフォルト設定）では、生存するのは Replicator系 + Scavenger系のみ。Opportunist（10コンポーネント、代謝18/tick）は全seedで早期絶滅。3つ目の身体型が消滅することで種族多様性が制限される。

Opportunist の絶滅原因は、Replicator（16/tick）との代謝コスト差 2/tick。10000 tickで20000エネルギーの累積ハンデとなる。この差を相殺するにはエネルギー供給の増加が必要。

### 探索の軸

1. **エネルギー生産量（energyProductionRate）**: 75 → 100〜140（Opportunistの生存閾値を探索）
2. **エネルギーノード数（energyNodeCount）**: 60 → 65〜80（空間的なエネルギーアクセス改善）
3. **エネルギー最大蓄積量（energyMaxStored）**: 2000 → 2500〜3000（バッファ効果）
4. **種族構成**: 全12種族 vs 厳選4〜6種族（種族間競争の緩和）
5. **初期個体数**: 12sp×3 vs 12sp×4（初期多様性の確保）

### Phase 1 所見

- **eProd=120以上でOpportunistが生存可能に**。これが最大の発見。3つ目の身体型が追加されることで種族多様性が飛躍的に向上
- 種族数を減らして初期個体数を増やす方針（Exp5, 6）は逆効果。行動バリアントによる空間的棲み分けが多様性維持に貢献しており、削減すると4+種族が達成困難に

## 分析

### 1. energyProductionRate 増加がOpportunist生存を可能にする

最大の発見は、eProd=120以上でOpportunist（10コンポーネント、代謝18/tick）が生存可能になること。デフォルト（eProd=75）では全8seedで早期絶滅していたOpportunistが、eProd=135では2/8 seedでpop≥2で10000tick生存。

構造的理由: Opportunistの追加代謝コスト 2/tick は、RECHARGEの頻度で吸収される。eProd=135×65ノード=8775エネルギー/tickの供給があれば、RECHARGEの待ち時間が短縮され、2/tickの追加コストの相対的影響が小さくなる。

### 2. eProd=135 + eN=65 の相乗効果

| 設定 | sp≥2 4+/8 |
|------|-----------|
| eProd=130 | 7/8 |
| eProd=135 | 3/8 |
| eProd=130, eN=65 | 7/8 |
| **eProd=135, eN=65** | **8/8** |

eProd=135単体（Exp16）は3/8と悪い結果。これはeProd増による人口増加がエネルギーノード争奪を激化させ、一部seedで崩壊するため。eN=65（+5ノード）の追加により空間的なエネルギーアクセスが改善され、競争が緩和される。

### 3. 行動バリアントが多様性の鍵

Exp5（5種族集中）、Exp6（4種族集中）、Exp7（6種族集中）はいずれも全12種族より悪い結果。理由:

- **空間的棲み分け**: Explorer, Wanderer, Avoider の移動パターンの違いが空間的分離を生む
- **確率的保険**: 12種族あれば、あるseedで特定のバリアントが偶然好位置に配置される確率が高い
- **ドリフト耐性**: 多くの種族プールから4+生存を達成する方が、少数精鋭から全員生存を要求するより容易

### 4. 種族構造の3層モデル

Exp19の結果から、種族の生存安定性は3層に分かれる:

**Tier 1（コア種族、6-8/8 生存）**: Rep-Expl, Scavenger, Replicator, Sca-Avoid, Rep-Avoid
- Replicator系とScavenger系の基本型+主要バリアント。資源再生サイクルの中核

**Tier 2（準安定種族、2-4/8 生存）**: Rep-Wand, Sca-Expl, Opp-Expl
- 一部のseedで中長期的に生存。seed依存性が高い

**Tier 3（不安定種族、0-1/8 生存）**: Opp-Wand, Opp-Avoid, Sca-Wand, Opportunist(base)
- ほぼ全seedで早期絶滅。eProd=135でも構造的に不利

4+種族の達成は、Tier 1（5種族）からの安定した供給 + Tier 2からの確率的追加による。

### 5. 物質循環は健全

全seedでresNodesが初期値160から310-430に増加。物質が「キャラクター→残骸→地面→リソースノード→キャラクター」と循環しており、資源枯渇は発生しない。

## 所見

### 最良設定

```
energyProductionRate = 135
energyNodeCount = 65
残りは 009 Exp12 と同一:
  remainsAbsorptionTicks = 600
  nodeRegenerationThreshold = 50
  nodeRemaining = 225
  energyMaxStored = 2000
  マップ 60×60, ore/crystal 各80
  12種族 × 各3体 = 36体（Settler/Recycler不使用）
```

### 達成したこと

- 全8seed（42, 123, 999, 7, 2024, 314, 555, 777）で4+種族（pop≥2）が10000tick時点で自己複製を継続
- 3つの身体型（Replicator, Scavenger, Opportunist）が共存するseedが出現
- seed 555 では7種族が10000tick時点で共存（最大多様性）

### 限界

1. **pop=2の種族は長期的に不安定**: 15000tick検証で seed 123, 777 が3種族に退行
2. **Opportunistの安定生存は2/8**: 3rd body typeの常時生存は達成できていない
3. **eProd=135はデフォルト75の+80%**: エネルギー供給の大幅増が必要。現在の仕様ではOpportunistの代謝ハンデが構造的に大きい

### 仕様変更の提案（目標達成を容易にするもの）

以下はゲーム仕様の変更提案であり、本探索では適用していない。

1. **代謝コスト逓減**: コンポーネント数に応じた代謝コストが現在は線形（各コンポーネントの代謝の合計）だが、コンポーネント数の平方根に比例させる（例: 10コンポーネントの代謝 = 合計 × √10/10 ≈ 0.32倍）などにすると、Opportunistの代謝ハンデが小さくなり、多コンポ���ネント種族の生存可能性が上がる
2. **残骸吸収速度のサイズ依存**: 多コンポーネントの残骸は吸収に時間がかかるようにする（例: componentCount × 100 tick）。Scavengerが大きい残骸を回収する時間的余裕が増え、ScavengerとReplicatorのニッチ分離が強化される
3. **エネルギー共有アクション**: キャラクター間でエネルギーを移転するアクション（例: SHARE_ENERGY）の追加。協調的な行動戦略が可能になり、新しい種族ニッチが生まれる。例えば「エネルギーを収集して子に渡す係」と「採掘に専念する係」の分業
4. **採掘効率のHarvester依存**: HARVESTの1回あたり取得量をHarvester数に依存させる（現在は固定1個）。複数Harvesterを持つ特化型生産者と、Harvester1つの汎用型の差別化が可能に
5. ~~**環境の不均一性**~~ — 撤回。全種族がOre+Crystal+Energyの3種ノードを必要とするため、空間的偏りを作っても棲み分けではなくアクセス障壁になるだけ。残骸は他種の行動の副産物であり地理的に固定できない。資源需要構造が全種族で同型である限り、環境の不均一性は種族間の差別化に寄与しない
