## 分析

### 1. nodeRemaining=225 が鍵: 初期資源量と再生サイクルの調和

Exp8(nodeRem=200)とExp11(nodeRem=250)はそれぞれ4/5だが、失敗するseedが異なる。nodeRemaining=225はこの中間で、両方の失敗パターンを回避する:

- **nodeRem=200の失敗（seed 999）**: 初期資源が不足し、Replicator系の人口が臨界質量に達する前に枯渇。Scavenger 2種のみに収束
- **nodeRem=250の失敗（seed 123）**: 初期資源過剰でReplicator系の初期ブームが大きすぎ、淘汰期にScavenger以外が全滅
- **nodeRem=225**: 適度な初期ブームの後、再生ノードで自律的繁殖が維持される

### 2. threshold=50 でReplicator系が「自律的繁殖」を獲得

007-008ではReplicator系の長期生存は「冬眠」（RECHARGE+REPAIRのみ、繁殖停止）に依存していた。Exp12では根本的に異なるパターンが出現した:

- **seed 42**: Rep-Expl が tick 3000 以降も **繁殖を継続**（tick 5000 で births=54）。再生ノードを発見・採掘し、自力で子を生産
- **seed 999**: Rep-Expl が tick 7000 で 31体のピーク。再生資源を利用した積極的繁殖
- **seed 2024**: Replicator(base) が tick 8000-9000 で 31-33体に増加。これも再生資源による

これは threshold=50 により**再生ノードが十分な頻度で出現**し、Replicator系が資源枯渇後も HARVEST → PROCESS → CRAFT → ASSEMBLE のフルサイクルを回せるようになったためである。

### 3. resNodes の大幅増加: 物質循環が確立

全seedで resNodes が初期値(160)の2-2.5倍に増加:

| seed | resNodes (tick 10000) | 倍率 |
|------|----------------------|------|

再生ノードの remaining は平均50-80程度（初期225と比較して小さい）だが、頻繁に出現するため実質的な資源供給量は維持される。

### 4. Scavengerの役割変化: 主役から脇役へ

007ではScavenger系が人口の60-95%を占めたが、Exp12では構成が逆転:

| seed | Replicator系 % | Scavenger系 % |
|------|----------------|---------------|
| 42 | 97% (33/34) | 3% (1/34) |
| 123 | 21% (4/19) | 79% (15/19) |
| 999 | 63% (26/41) | 37% (15/41) |
| 7 | 73% (19/26) | 27% (7/26) |
| 2024 | 89% (31/35) | 11% (4/35) |

5seedのうち4seedでReplicator系が過半数。資源再生によりReplicatorの自律的繁殖が可能になったことで、残骸に依存するScavenger系の相対的優位が低下した。

ただしScavengerは「死亡時の残骸回収」という独自ニッチを維持しており、少数ながら全8seedで10000 tick生存を達成している。

### 5. 動的均衡の質的向上

007との最大の違いは、births/deathsの質である:

- **007**: births/deathsの大半はScavengerのリサイクル経済内で完結（残骸→DISASSEMBLE→CRAFT→ASSEMBLE→死亡→残骸...）
- **Exp12**: births/deathsにReplicator系の HARVEST→PROCESS→CRAFT→ASSEMBLE サイクルが大きく寄与

seed 42 の tick 7000-9000 では、births=53-59/500tick のうち大半がRep-Expl（再生ノードを採掘して繁殖）。これは「Replicatorが自律的に繁殖し続ける動的な生態系」であり、007の「Scavenger中心の閉じたリサイクル経済」とは質的に異なる。

### 6. 唯一の失敗: seed 314 (2種族)

Rep-Wand(17) + Scavenger(9) の2種族に収束。Rep-Wand以外のReplicator系が初期配置で不利な位置にあり、淘汰期にRep-Wandのみが生存。Scavengerは残骸を回収して共存するが、3種族目が確保できなかった。

## 所見

### 最良設定

```
remainsAbsorptionTicks = 600
nodeRegenerationThreshold = 50
nodeRemaining = 225
energyMaxStored = 2000  (変更なし)
```

その他のパラメータは007と同一。

### 達成したこと

- 8seed中7seedで目標条件を達成（87.5%）
- リソースノード再生により、Replicator系が冬眠ではなく繁殖を継続する生態系を実現
- Scavengerは残骸回収のニッチで少数ながら安定共存
- 物質保存則が維持されつつ、物質が「キャラクター → 残骸 → 地面 → リソースノード → キャラクター」と循環

### 残る課題

1. **Scavenger系の縮小**: 少数（1-15体）での共存にとどまり、大集団を形成しない。残骸在庫が限定的なため
2. **Opportunist系の早期絶滅**: 全seedで tick 2000-5000 に絶滅。10コンポーネントの高代謝コスト（18/tick）が資源再生環境でも不利に作用
3. **seed 314 の失敗**: 初期配置の偶然に起因。パラメータ調整のみでは完全に解消できない
