# 005: バリアント間競争

日付: 2026-04-04

## 目的

3種族 × 4バリアント = 12プログラムを同時投入し、行動戦略の違いが生存に与える影響を確認する。

### バリアント定義

| バリアント | suffix | 移動時の行動 |
|---|---|---|
| A (現行) | なし | 必要な資源→デフォルト目的地→方向持続→放浪 |
| B (探索型) | -Expl | 必要な資源→**デフォルト目的地スキップ**→方向持続→放浪 |
| C (気まぐれ型) | -Wand | **energy>=5500で放浪**→必要な資源→デフォルト目的地→方向持続→放浪 |
| D (回避型) | -Avoid | **半径5以内のキャラクターを回避**→必要な資源→デフォルト目的地→方向持続→放浪 |

A-D共通: エネルギーヒステリシス（reg1）、方向持続（reg2）は全バリアントで同一。

仕様追加: 回避型のために `angle_away_from_nearest` fn値を追加（`(angle_to_nearest + 180) % 360`）。

### 各バリアントの戦略的特徴

- **A**: 既知の資源に向かい、なければ最寄りの対象へ移動。Scavengerは EnergyNode付近で待機。
- **B**: 必要な資源のみを追い、それ以外の情報を無視して探索。マップ未踏領域の発見に有利。
- **C**: エネルギーが充足している間は資源を無視して探索。局所的な資源枯渇を回避し、新領域を発見。
- **D**: 他キャラクターから距離をとることで、個体間の資源競合を緩和。人口分散。

## 分析

### 1. 単一の最強バリアントは存在しない

3つのseedで5000tick生存を達成したバリアントの組み合わせが完全に異なる:
- seed 42: Replicator (A) + Rep-Expl + Scavenger (A)
- seed 123: Rep-Expl + Sca-Wand
- seed 999: Rep-Avoid

初期配置（キャラクターとノードの位置関係）が戦略の有効性を大きく左右する。これは生態系における偶然性（ドリフト）の影響が強いことを示す。

### 2. バリアント別の傾向

**Replicator系** — 最も多くのバリアントが生存:
- Rep-Expl（探索型）: 2/3 seedで生存。デフォルト目的地に固執しないことで、マップ全体の資源を効率的に利用。
- Replicator（A）: 1/3で生存。安定だが初期配置に依存。
- Rep-Wand（気まぐれ型）: 0/3で生存だが2000tick以上持続。中程度の探索効果。
- Rep-Avoid（回避型）: 1/3で生存。seed 999では**唯一の最終生存者**となり、tick 3500以降は人口5で静的平衡に到達（誕生0、死亡0）。個体が分散して資源競合を回避した結果。

**Scavenger系** — 戦略によって結果が極端に異なる:
- Scavenger（A）: 1/3で生存。EnergyNode待機戦略はseed 42で最大勢力（16体）を築く。
- Sca-Wand（気まぐれ型）: 1/3で生存。seed 123で12体まで増加。
- Sca-Expl（探索型）: 0/3で生存。EnergyNode待機を放棄すると、エネルギー不足で早期死亡しやすい。
- Sca-Avoid（回避型）: 0/3で生存。残骸発生地点に集まる必要があるのに回避行動が矛盾。

**Opportunist系** — 全seedで最終的に絶滅:
- Opp-Wand（気まぐれ型）: seed 999でtick 3496まで生存し、最も長寿のOpportunistバリアント。
- 10コンポーネントの高代謝（18/tick）が全バリアントに共通の足枷。

### 3. 回避型の特殊な動態（seed 999）

Rep-Avoidがseed 999で唯一の最終生存者となった。この個体群はtick 3500以降、人口5・資源ノード11で完全な静的平衡に到達した:
- 5000tickまで誕生0、死亡0
- エネルギー蓄積50000前後で安定
- 残骸66（固定）

回避行動により個体が分散し、各個体が独自の資源・エネルギー領域を確保した結果と考えられる。ただし、繁殖が停止しているため進化的には行き止まりである。

### 4. 探索型 vs 定住型

Replicator系では探索型（B）が定住型（A）を上回る傾向がある一方、Scavenger系では逆:
- Replicator: 資源ノードはマップ全体に分散しているため、探索によるノード発見が有利
- Scavenger: 残骸は他キャラクターの死亡地点に発生するため、人口密集地（EnergyNode付近）での待機が有利

この違いは、資源の空間分布特性を反映している。静的資源（ノード）には探索が有効、動的資源（残骸）には待機が有効。

### 5. 気まぐれ型の意外な健闘

気まぐれ型（C）はエネルギーを浪費する非効率な行動に見えるが:
- Rep-Wand: 全seedで1800tick以上生存
- Sca-Wand: seed 123で唯一の最終生存Scavenger（12体）
- Opp-Wand: seed 999でOpportunist最長生存

気まぐれな探索により、他個体が消費し尽くした局所的な資源枯渇地帯を脱出できる可能性がある。「非効率な探索」がマクロには資源分布への適応力として機能している。

## 所見

- バリアント間競争の結果は初期配置に強く依存し、「最強の行動戦略」は存在しない
- Replicator系は探索型（B）が最も汎用的。Scavenger系は定住型（A）が基本的に有利だが、配置次第で気まぐれ型（C）も成功する
- Opportunist系は行動戦略のバリエーションでは10コンポーネントの代謝ハンディキャップを克服できない
- 回避型（D）は静的平衡を生みやすく、人口分散には有効だが繁殖停止のリスクがある
- 資源の空間分布特性（静的/動的）に応じて最適な探索戦略が異なるという結果は、均一な行動戦略よりも環境適応型の戦略が有利であることを示唆する
