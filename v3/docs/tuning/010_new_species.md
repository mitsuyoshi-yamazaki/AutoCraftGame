# 010: 新種族（Settler / Recycler）の投入と生態系への影響

日付: 2026-04-04

## 目的

新たに2種族を投入し、既存12種族の生態系にどのような影響を与えるか分析する。

### 新種族

**Settler（定住型一次生産者）** — 初期6体
- 身体: Replicator と同一（9コンポーネント、代謝16/tick）
- 行動差異: 充電閾値が低い（2500-4500 vs Replicator の 4000-6000）。エネルギー枯渇ギリギリまで採掘を続ける。充電モード解除後は ResourceNode に直行（Replicator は wander で分散）
- ニッチ: リソースノード付近に定住し、採掘時間を最大化する「短命高効率型」

**Recycler（残骸優先ハイブリッド）** — 初期3体
- 身体: Opportunist と同一（10コンポーネント、代謝18/tick）
- 行動差異: 残骸を最優先で探索・分解し、なければ ResourceNode で採掘にフォールバック。充電モード解除後も残骸を優先探索
- ニッチ: Scavenger（残骸専門）と Replicator（資源専門）の中間。残骸寄りの日和見型

## 分析

### 1. Settler の効果: 初期ブームへの正の寄与、その後絶滅

Settler は tick 0-1500 に集中的に資源を採掘する。低い充電閾値（2500）によりエネルギー管理が緩く、初期リソースが豊富な時期に素早く採掘→加工→組立のサイクルを回す。しかし:

- 充電閾値が低すぎるため、初期リソース枯渇後にエネルギー切れで餓死しやすい
- tick 1500-4300 で全滅。繁殖には至らない場合が多い
- 死亡時に残骸を残し、Scavenger への資源供給に寄与

Settler は**一次生産者としての直接的な長期生存**ではなく、**初期にリソースを効率的に消費し残骸として生態系に還元する**役割を果たしている。

### 2. Recycler の構造的限界: 代謝18/tickは致命的

Recycler は全8seedで tick 800-1800 に絶滅。Opportunist と同じ10コンポーネント（代謝18/tick）が構造的に不利。残骸優先の行動パターンは差別化になっているが、初期段階（残骸が少ない）での生存率が低い。

残骸が出始める tick 500-1000 頃にはすでにエネルギー不足で瀕死であり、DISASSEMBLE の機会を得る前に死亡するケースが多い。

### 3. 初期45体による資源競争の激化

009 Exp12（36体）に比べて初期人口が25%増加。これによりエネルギーノードの競争が激化し:

- seed 999: Replicator系が全滅（009では4種族生存） → 2種族に退行
- seed 314: Scavenger単独収束（009では3種族生存）
- seed 7: 14体/2種族（009では26体/4種族）

初期人口増加の影響は、新種族自体の性能よりも大きいインパクトを持っている。

### 4. 達成率低下の主因は初期競争

009 Exp12 で OK だった seed 999, 7, 314 が今回 NG に転じた。共通点は「初期45体でのエネルギー競争で Replicator系が弱体化」。Settler 6体が資源を大量消費する初期フェーズで、Replicator系がリソースにアクセスする機会が減少し、冬眠に入る前にエネルギー切れで死亡するパターン。

### 5. 生存バリアントの構造は009と類似

最終的に生存する種族は 009 と同じ構造: **Replicator系（Rep-Expl/Rep-Wand/Rep-Avoid） + Scavenger系（Scavenger/Sca-Avoid/Sca-Wand）** の組み合わせ。新種族の追加は長期的な生態系構造を変えていない。

### 6. seed 777 で Sca-Wand が22体の大勢力

seed 777 では Sca-Wand（Scavenger-Wanderer）が tick 8000-10000 で22体まで増加。009 Exp12 ではこのバリアントは1/8でしか生存しなかったが、今回は初期の資源消費パターンの違いにより異なる局所均衡に到達した。

## 所見

### Settler

初期の「使い捨て一次生産者」として機能し、残骸を通じて Scavenger への資源供給に寄与する。長期生存は不可能だが、生態系の初期ダイナミクスに影響を与えている。充電閾値をさらに下げると完全な「使い捨て」になり、上げると Replicator との差が縮まる。現在の 2500-4500 はトレードオフの一点として妥当。

### Recycler

10コンポーネント（代謝18/tick）は現在のパラメータ環境で構造的に不利であり、長期生存は困難。Opportunist と同じ課題を抱えている。ハイブリッド戦略の利点が代謝コストのデメリットを上回るには、エネルギー供給がより潤沢な環境が必要。

### 全体

新種族の追加は生態系の多様性向上にはつながらなかった。達成率は 87.5% → 62.5% に低下。主因は初期人口増加（36→45）による資源競争の激化。新種族のニッチは既存種族と部分的に重複しており、独自の長期生存戦略を確立できていない。
