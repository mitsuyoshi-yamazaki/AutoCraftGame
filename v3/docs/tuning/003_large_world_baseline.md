# 003: 大規模ワールド + 情報制限ベースライン

日付: 2026-04-03

## 目的

以下の変更を適用した状態での3種族の動態を確認する。

- ワールドサイズ 20×20 → 40×40
- ノード密度を半減（面積あたり）
- エネルギー生産量を半減
- SENSE_RANGE=10（情報取得範囲の制限）
- recharge閾値を4000に引き上げ
- wanderフォールバック（探索行動）
- エネルギー0未満禁止、飢餓時durability消耗2倍

## 分析

### 1. 002との比較: 成長速度の大幅な低下

002（20×20、高密度）では初期15体が500tickで25-27体に急増したが、今回は500tickで16-21体にとどまる。原因:
- ノード密度の低下 → 最寄りノードまでの移動距離が増加
- SENSE_RANGE=10 → 検知できないノードが存在し、wander探索が必要
- エネルギー生産量半減 → 充電に時間がかかる
- recharge閾値4000 → 充電に専念する時間が増加

### 2. 資源の持続性

002では資源がtick 1000-2000で枯渇したが、今回はtick 5000時点でも19-33ノードが残存。面積あたりの密度低下でノードへのアクセスが制限され、資源消費速度が大幅に低下した。これにより**資源枯渇後の静的平衡（001の問題）が解消**され、5000tick全体を通じて資源ベースの複製が継続。

### 3. Scavengerの相対的優位の低下

002では全seedでScavengerが圧倒的に優位（34-38体）だったが、今回はseedによって結果が異なる:
- seed 42: Scavenger優位（28体）だが、成長に時間がかかる
- seed 123: Scavenger微優位（12体 vs Rep 7体）で安定
- seed 999: tick 3000時点でReplicatorが15体で優位、その後Scavengerが逆転

広い空間では残骸の発生位置が分散し、Scavengerが残骸を見つけにくくなったことが要因。

### 4. Opportunistの生存改善

002では全seedでtick 1200-4400に絶滅したが、今回はseed 42と123でtick 5000まで1-2体が生存。資源消費が緩やかなため、Opportunistが活動できる余地が残っている。ただし繁殖力は低く、勢力拡大には至らない。

### 5. wander探索の効果

SENSE_RANGE=10の制限下でwander（energy % 360）によるフォールバック移動が機能。エネルギーは代謝で毎tick変化するため方向が変わり、結果としてキャラクターが未探索領域に移動できている。NOOPフォールバックだった場合、SENSE_RANGE外にしかターゲットがない個体は完全に動作停止していたはず。

### 6. エネルギー経済の変化

002ではtick 2000以降エネルギーが常に0付近だったが、今回はseedによって10000-40000の余裕がある。エネルギー生産量半減（75/tick × 18 = 1350/tick）にもかかわらず、人口が少ないため競合が緩和されている。飢餓死（durability消耗2倍）は発生しているが、全体的なエネルギー不足は002ほど深刻ではない。

### 7. 種族間の多様性

002に比べ、seedごとの種族バランスのばらつきが大きい。配置の運（初期位置とノード位置の距離関係）が広い空間ではより大きく影響するためと考えられる。

## 所見

- 大規模化・密度低下・情報制限の組み合わせにより、002の「急速な資源枯渇→Scavenger一極支配」パターンが緩和された
- 3種族が5000tick共存するseedが存在（42, 123）。002では全seedでOpportunistが絶滅していた
- 資源が長期間残存し、成長と淘汰が緩やかに進行する生態系になっている
- seedによる変動が大きく、初期配置の影響が強い。長期的な動態の安定性を確認するにはより多くのseedや10000tick以上の実行が有効
