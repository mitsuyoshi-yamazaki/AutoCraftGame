# 003: 大規模ワールド・資源削減ベースライン

日付: 2026-04-03

## 目的

ワールドサイズ拡大（20×20→40×40）、ノード密度削減（面積あたり約1/3）、エネルギー生産量半減後のシミュレーション動態を確認する。

## 分析

### 1. 動的フェーズの大幅な延長

002では資源枯渇後すぐに静的平衡に達したが、003では**tick 5000まで活発な誕生・死亡が継続**している。

- seed 42: tick 4000-5000でまだ36誕生/39死亡
- seed 123: tick 4000-5000で39誕生/39死亡
- 002と比較して動的フェーズが3-4倍に延長

原因:
- 広い空間で資源ノードが分散 → 全資源の一斉枯渇が発生しない
- エネルギー生産量の削減 → エネルギー競争が激化し、持続的な死亡が発生
- 死亡 → 残骸 → Scavengerの複製 → 新たな死亡 というサイクルが長期間持続

### 2. 資源が枯渇しない

002では全ResourceNodeがtick 1000-2000で枯渇したが、003では**10000 tick時点でも10-21ノードが残存**。

- 広い空間のためキャラクターが全ノードに到達できない
- 「遠方にあるが未消費のノード」が天然のリザーブとなる
- これが「海を越えた先のリソース島」に相当する地形効果を自然に生んでいる

### 3. 最終的には静的平衡に収束

10000 tick時点では全seedで**人口10体前後に安定化**し、誕生・死亡がほぼ停止する。

- 002の静的平衡(tick 2000-)と比較してはるかに遅い(tick 7000-8000-)が、構造的には同じ問題
- 最終状態では残存エネルギーが50000前後（最大54000の90%以上）と大幅に余り、淘汰圧が消滅
- Scavengerは被食者（Replicator）の死亡に依存するため、Replicatorが安定するとScavengerも複製不能に → 最終的にScavenger絶滅/1体残存

### 4. Opportunistの評価が改善

- seed 42では**tick 5000時点でOpportunist 5体が生存**（002では全seedで絶滅）
- 広い空間で両方のニッチ（リソース採取+残骸分解）を活かせる局面がある
- ただし長期的にはやはり専門種に劣位（seed 42でもtick 6752で絶滅）

### 5. seed間のばらつき拡大

| 指標 | seed 42 | seed 123 | seed 999 |
|------|---------|----------|----------|
| 5000 tick 総誕生 | 199 | 180 | 82 |
| 動的フェーズ | ~7000 tick | ~7500 tick | ~4000 tick |
| Opp生存期間 | 6752 tick | 1599 tick | 699 tick |

seed 999は総誕生82と他の半分以下。初期配置の偏りが大きく影響している。広い空間ではノード配置のランダム性が生態系の展開を大きく左右する。

### 6. Remainsの蓄積

10000 tick時点でRemains 34-55個が残存。これはScavengerが消費しきれなかったもの。Scavenger個体数が少ない場合、Remainsは事実上「死蔵」される。

## 002との比較まとめ

| 観点 | 002 (20×20) | 003 (40×40) |
|------|-------------|-------------|
| 資源枯渇 | tick 1000-2000で全枯渇 | 10000 tickでも10-21ノード残存 |
| 動的フェーズ | ~2000 tick | ~5000-7500 tick (×2.5-3.5) |
| 最終人口 | 40-44 | 10 |
| エネルギー余剰 | なし（全消費） | あり（最終的に余る） |
| 種族多様性 | Scavenger一強 | seed依存で多様 |
| Opportunist生存 | 全seed絶滅 | 1/3 seedで5000 tickまで生存 |

## 課題

1. **長期的な静的平衡**: 動的フェーズは延長されたが、10000 tick付近で依然として静的平衡に到達する。人口10体は少なく活性が低い
2. **人口維持の難しさ**: エネルギー密度低下により人口キャパシティが下がり、少数個体で安定してしまう。資源は残っているが到達できない個体が死ぬ
3. **Scavengerの長期的脆弱性**: 被食者の死亡に完全に依存するため、系が安定するとScavengerの役割がなくなる
