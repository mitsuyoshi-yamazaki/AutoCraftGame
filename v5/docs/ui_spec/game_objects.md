# GUI描画対象オブジェクト一覧 — v5

ゲームシステム上、連続座標（Position）を持ち、GUIの連続空間上に描画しうるオブジェクト種別を列挙する。

全オブジェクトは連続座標上の図形として描画される。各オブジェクトは衝突半径を持ち、描画サイズはこの半径に基づく。

---

## 1. ResourceNode（資源ノード）

マップ上に配置された採取可能な資源源。キャラクターが一定距離内（INTERACT_RANGE）からHARVESTアクションで原料を取得する対象。有限資源であり、枯渇すると消滅する。地面に蓄積された物質から再生する場合がある。

- **id** — 一意な識別子
- **type** — ノード種別
  - `OreNode`（鉱石ノード）: Oreを産出
  - `CrystalNode`（結晶ノード）: Crystalを産出
- **remaining** — 残存資源量（整数）
- **position** — 連続座標 `{x, y}`（浮動小数点数）
- **createdAt** — 生成された tick（整数）。初期配置ノードは 0、再生ノードは再生時のtick

### 描画要件

- 衝突半径（RESOURCE_NODE_RADIUS）に基づくサイズの角丸矩形で描画する
- remaining量に応じて濃淡が変化（多い＝濃い、少ない＝薄い）
- 資源の種類が色で明確に区別される（OreNode: 灰青色、CrystalNode: 薄緑色）

### LOD（簡略描画）

画面上サイズが閾値以下の場合、小さな角丸矩形に簡略化。色と透明度は同一ルール。

### 選択時の表示

- 黄色い円形リングで強調
- 詳細パネル: type, 位置, remaining, 生成tick

## 2. EnergyNode（エネルギーノード）

マップ上に配置されたエネルギー供給源。毎tickエネルギーを生産し、上限まで蓄積する。キャラクターが一定距離内からRECHARGEアクションで回収する。

- **id** — 一意な識別子
- **productionRate** — tickあたりのエネルギー生産量
- **stored** — 現在の蓄積量
- **maxStored** — 蓄積量の上限
- **position** — 連続座標 `{x, y}`（浮動小数点数）
- **createdAt** — 生成された tick（整数）。初期配置ノードは 0

### 描画要件

- 衝突半径（ENERGY_NODE_RADIUS）に基づくサイズのダイヤモンド形で描画する
- stored量に応じて濃淡が変化（多い＝明るい、少ない＝暗い）
- ResourceNodeともCharacterとも視覚的に区別できること

### LOD（簡略描画）

画面上サイズが閾値以下の場合、小さなダイヤモンド形に簡略化。色と透明度は同一ルール。

### 選択時の表示

- 黄色い円形リングで強調
- 詳細パネル: 位置, stored/maxStored, productionRate, 生成tick

## 3. Remains（残骸）

キャラクターが死亡した際にその位置に残されるオブジェクト。コンポーネントとインベントリを保持し、他のキャラクターがDISASSEMBLEで回収できる。一定tick経過後に地面に吸収されて消滅する。

- **id** — 一意な識別子
- **components** — 死亡キャラクターのコンポーネント一覧（v3のRegisterは含まれない）
- **inventory** — 死亡キャラクターのインベントリ
- **position** — 連続座標 `{x, y}`（浮動小数点数）
- **createdAt** — 生成された tick（整数）

### 描画要件

- 衝突半径（REMAINS_RADIUS）に基づくサイズの破断円弧で描画する
- 内容物の多寡に応じて中央の充填円サイズが変化する
- 完全に空になったら消滅する（DISASSEMBLEで全回収時）
- 一定tick経過で地面に吸収されて消滅する

### LOD（簡略描画）

画面上サイズが閾値以下の場合、小さな円に簡略化（灰色）。

### 選択時の表示

- 黄色い円形リングで強調
- 詳細パネル: 位置, 吸収までの残りtick数, コンポーネント一覧, インベントリ

## 4. Character（キャラクター）

自律行動するゲームオブジェクト。`active` が true なら活性（Active）、false なら非活性（Inactive）。

- **id** — 一意な識別子（例: `char-001`）
- **species** — 種族名（生成時のプログラム名に由来、ASSEMBLE時に親から継承）
- **position** — 連続座標 `{x, y}`（浮動小数点数）
- **velocity** — 速度ベクトル `{vx, vy}`（浮動小数点数）
- **durability** — 現在の耐久値（毎tick -1、0以下で死亡）
- **energy** — 現在のエネルギー量
- **components** — 搭載コンポーネント一覧
- **inventory** — 所持アイテム（アイテム名 → 個数）
- **mass** — 質量（コンポーネント+インベントリの原料換算合計、情報パネルで表示）
- **active** — VM実行中かどうか（boolean）
- **pc** — プログラムカウンタの現在位置
- **registers** — VMレジスタ r0-r7 の値（number[8]）
- **memory** — VMメモリ（number[]）
- **最大耐久値** — Frame数 × FRAME_DURABILITY（componentsから導出）

### 選択時の詳細パネル（SelectedPanel）

| 項目 | 表示内容 |
|------|---------|
| ID | キャラクターID |
| Active/Inactive | active状態 |
| Species | 種族名 |
| Age | 生存tick数 |
| Position | 座標 |
| Mass | 質量 |
| Durability | 現在値 / 最大値 |
| Energy | エネルギー |
| Actions | 前tickの予約アクション一覧 |
| Components | コンポーネント一覧 |
| Inventory | アイテム一覧 |

### VM状態パネル（VMPanel）

キャラクター選択時のみ、SelectedPanelの下に表示される。VMデバッグ用の詳細情報。

| 項目 | 表示内容 |
|------|---------|
| PC | プログラムカウンタの現在位置 |
| Registers | r0-r7 の値 |
| Memory | メモリサイズ（ワード数） |
| VM Active | VM起動状態 |
| Actions | 前tickの予約アクション一覧（SelectedPanelと同内容） |
| Failed | 失敗したアクションのop名と失敗理由（ActionFailureReason）の一覧 |

### 描画要件（Active）

- 単細胞生物のメタファー。曲線で構成される円形の見た目
- 衝突半径（CHARACTER_RADIUS）に基づくサイズの円で描画する
- 構造（外→内）:
  1. 細胞質（暗い半透明背景円）
  2. コンポーネントリング（外周の色分け円弧、各コンポーネント種別に固有色。v3のRegister色は含まれない）
  3. エネルギーリング（内側の金色円弧、エネルギー比率で長さ変化）
  4. 核（中央の円、durability比率でサイズ変化、Processor色）

### 描画要件（Inactive）

- Activeと同様の構造だが、全体にグレースケール + 半透明の黒を重ねて「停止中」を表現

### LOD（簡略描画）

画面上サイズが閾値以下の場合、黒円の中にdurability比率に応じたサイズの赤円を描画。非アクティブは灰色。

### 選択時の表示

- 黄色い円形リング + SENSE_RANGE円（灰色の破線円）
- 詳細パネル: 上記テーブル参照

## 5. Ground（地面セル）

ワールドを1×1の内部グリッドに分割した各セル。残骸から吸収された物質量を追跡する。目に見えるオブジェクトとしては描画されないが、クリックで選択可能。

- **cellX, cellY** — セル座標（整数）
- **ore** — 吸収済みOre量（整数）
- **crystal** — 吸収済みCrystal量（整数）

### 描画要件

- 通常時は描画しない（透明）
- 選択時のみ黄色い矩形枠（1×1セル範囲）を表示

### 選択時の表示

- 黄色い矩形枠
- 詳細パネル: セル座標, Ore量, Crystal量

## 6. 壁（ワールド境界）

ワールドの矩形境界。不動オブジェクトであり、キャラクターが衝突すると反発力が発生する。

### 描画要件

- ワールドの矩形領域の外周を線で描画する
- 色は暗い灰色（`#333333`）、背景から区別できる程度
- 選択不可

## 補足: 位置を持たない概念（描画対象外）

以下はゲームシステム上の重要な概念だが、マップ座標を持たないため連続空間上への直接描画対象ではない。サイドパネルやイベントログでの情報表示に用いる。

- **Inventory内アイテム** — Ore, Crystal, Metal, Circuit, Frame, Actuator 等。キャラクターの所持品として表示
- **VMメモリ/レジスタ** — キャラクターの内部状態。選択時の詳細パネルでサイズ・値を表示
- **SimulationEvent** — character_spawned / character_died。イベントログとして時系列表示
- **World統計** — 現在tick、生存キャラクター数、累計誕生・死亡数等。統計パネルで表示
- **GroundGrid** — 地面セル単位の吸収物質量。Ground選択時のみ詳細パネルで表示
