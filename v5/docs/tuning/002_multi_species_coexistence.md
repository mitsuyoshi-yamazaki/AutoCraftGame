# 002: 複数種族の長期共存

**日付**: 2026-04-07
**目標**: 複数の種族が10000tick以上共存するパラメータ・プログラムの組み合わせを発見する

## 条件

### ベースライン（001からの変更なし）

| パラメータ | 値 |
|-----------|-----|
| マップ | 60×60 |
| OreNode | 50, remaining=225 |
| CrystalNode | 50, remaining=225 |
| EnergyNode | 40, prod=105, max=1600 |
| frameDurability | 5000 |
| agingThresholdN/M | 3000/6000 |
| assembleEnergyTransfer | 500 |

**種族**: Replicator×3のみ（001で達成した自己複製プログラム）

### ベースライン結果（3 seed）

| seed | 最終 | ピーク | 誕生 | 死亡 | 絶滅tick |
|------|------|--------|------|------|---------|
| 42 | 0 | 98 | 95 | 98 | 10907 |
| 123 | 0 | 76 | 73 | 76 | 10057 |
| 999 | 0 | 69 | 66 | 69 | 13036 |

**パターン**: 成長(0-3000) → 停滞(3000-7000) → 老化死滅(7000-11000) → 全滅

### ベースライン分析

1. **1世代のみの繁殖**: tick 3000以降、新規誕生がゼロ。資源ノード枯渇により2世代目の繁殖不可能
2. **一斉老化死**: 全個体がtick 0-2000に誕生。agingThresholdN=3000到達後、代謝増大で一斉に死亡
3. **資源再生の遅れ**: 死亡→残骸→地面吸収→ノード再生のサイクルが完了する頃には全個体が死亡
4. **REPAIR未使用**: 既存Replicatorプログラムにはrepair動作がなく、耐久値の回復不可

## 探索過程

### 実験1: Gatherer + Scavenger アプローチ

**仮説**: 資源採取種(Gatherer)と残骸リサイクル種(Scavenger)の2種で物質循環を実現

**Gatherer**: Frame×2, Actuator, Harvester, Charger, Assembler, Processor, Sensor, MemoryCore×2 (10部品, 代謝18)
**Scavenger**: Frame×2→3, Actuator, Disassembler, Charger, Assembler, Processor, Sensor, MemoryCore×2 (10-11部品, 代謝18-19)

**結果**: Scavengerは常にtick 5700-15000で絶滅。以下の原因:

1. **エネルギー死の渦**: Scavengerは残骸がない初期(0-6000tick)に行動できず、代謝のみでエネルギー消費。密集したGatherer群とのエネルギー競合で充電不能に陥る
2. **0エネルギーからの回復不能**: 全アクション（SENSEですら5エネルギー）にコストがかかるため、エネルギー0に達すると一切の行動が不可能となり永続的な飢餓状態に入る
3. **加齢代謝の影響**: tick 8000以降、代謝が2倍以上に増加。充電と修理のエネルギー収支が破綻
4. **残骸出現のタイミング不一致**: Gathererの死亡はtick 6000以降だが、Scavengerは既にエネルギー不足で弱体化

**結論**: 純粋なScavengerニッチは現在の仕様では成立困難。初期からの生存手段がない。

### 実験2: Pioneer + Survivor アプローチ

**仮説**: 同一コンポーネント構成・異なる行動戦略の2種で共存を実現

**共通構成**: Frame×2, Actuator, Harvester, Charger, Assembler, Processor, Sensor, MemoryCore×2 (10部品, 代謝18)

| 特性 | Pioneer | Survivor |
|------|---------|----------|
| 充電閾値 (enter/exit) | 250/700 | 300/800 |
| 修理閾値 (enter/exit) | 2000/4000 | 2000/5000 |
| 徘徊パターン | 90°刻み | 45°刻み |
| 組立エネルギー閾値 | 700 | 700 |
| 戦略 | やや積極的充電、狭い探索 | 保守的充電、広い探索 |

**パラメータ変更**:

| パラメータ | 変更前 | 変更後 | 理由 |
|-----------|--------|--------|------|
| EnergyNode数 | 40 | 60 | エネルギー供給増加（修理コスト200/回に対応） |
| energyProductionRate | 105 | 200 | 同上 |
| agingThresholdN | 3000 | 8000 | 繁殖可能期間の延長。2世代目が繁殖する時間的余裕を確保 |
| agingThresholdM | 6000 | 12000 | 同上 |

### フェーズ分析

1. **成長期 (tick 0-2000)**: 両種が急速に繁殖。Survivorが保守的充電戦略により多く繁殖(169 vs 88)
2. **飽和期 (tick 2000-5000)**: 資源枯渇により繁殖停止。人口265で安定
3. **第1世代崩壊 (tick 5000-6000)**: 耐久値上限(10000)到達。修理が追いつかない個体から死亡。144体が死亡し133体の残骸が発生
4. **第2世代繁殖 (tick 6000-8000)**: 資源ノード再生(13→54)。生存個体が新資源で繁殖再開。Survivorが支配的に
5. **安定振動 (tick 8000-15000)**: Survivorが50-110で振動。修理により長寿命を実現し、資源サイクルに合わせて繁殖
6. **Pioneer残存**: Pioneer個体数は1-5に減少するも完全には絶滅しない

### 種族間の動態

- **Survivorの優位性**: 保守的な充電戦略(exit=800 vs 700)によりエネルギーバッファが大きく、行動効率が高い。修理閾値が高い(exit=5000)ため、より多くの時間を繁殖に使える
- **Pioneerの生存**: 90°刻み徘徊により異なる空間探索パターン。Survivorが占有していない資源ノードを発見する確率がわずかに異なる
- **競争的排除の不完全性**: 同一ニッチだが微妙な行動差(充電タイミング、徘徊角度)により、完全な競争的排除が起きずPioneerが1-5個体で残存

## 仕様変更の提案

目標は達成したが、以下の仕様変更によりさらに豊かな生態系が実現可能:

1. **パッシブエネルギー回復**: エネルギー0からの回復が不可能な現状は、Scavengerのような異ニッチ種の設計を著しく困難にしている。エネルギーノード近接時の微量パッシブ回復（アクション不要）があれば、0エネルギー死の渦を回避でき、より多様なニッチが成立する

2. **資源タイプの分化**: 全コンポーネントがMetalとCircuit（→OreとCrystal）を必要とするため、資源利用の棲み分けが困難。特定の資源のみで構成可能なコンポーネントがあれば、OreSpecialistとCrystalSpecialistのような種が自然に分化できる

3. **インベントリ重量ペナルティ**: inventoryMetabolismPerItem=0のため、資源を大量に抱え込むことにコストがない。適度なペナルティがあれば、軽量で素早い種と重量で頑健な種という体格差による棲み分けが生まれる

4. **DISASSEMBLE効率の向上**: 現状のDISASSEMBLEは1回のアクションで1アイテムしか取得できず、残骸のリサイクルに非常に多くのtickを要する。効率向上により、Scavengerニッチの実用性が向上する
