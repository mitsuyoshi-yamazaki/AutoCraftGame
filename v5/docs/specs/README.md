## v3からの主な変更点

### プログラムモデルの刷新

v3の「条件→アクション」ルール列を廃止し、16bit VMによる汎用プログラムに置き換え。

- ノイマン型メモリモデル（プログラムとデータが同一空間、アドレスは循環）
- 自身のプログラムを通常のメモリ操作で読み書き可能
- I/O空間を介してゲーム世界と相互作用

### アクションモデルの変更

- 1tickあたり複数アクション実行可能（異なる種別同士）
- アクションは「予約→一括実行」方式（SENSEのみ即時実行）
- WRITEはブロック書き込み（コスト = length × 比例定数）
- ASSEMBLEのコンポーネント構成をランタイムに決定
- 対象指定にローカルIDを使用

### コンポーネントの変更

- Registerコンポーネントを廃止（レジスタはVMに内蔵）
- MemoryCoreがVM用メモリを提供（1個あたり1024ワード）

### ツールチェイン

- アセンブラ → バイナリ
- Mini-C → アセンブラ → バイナリ

## 互換性

v3以前との互換性は一切不要。
