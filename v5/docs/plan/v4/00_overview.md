# v4 計画: 概要

## 目標

キャラクターのプログラムを変化可能にし、進化が創発するシミュレータを実現する。

## v4の最小要件

自己複製が可能な最小VMを作り、身体構成とパラメータの変異を実現する。

## v3からの主な変更点

- プログラムモデル: ルール列 → VM命令列（アセンブラ相当の汎用プログラム）
- メモリモデル: レジスタのみ → ノイマン型統一メモリ空間
- WRITE: プログラム丸コピー → 1ワード単位のプリミティブ書き込み
- ASSEMBLE: components引数がハードコード → ランタイムに決定
- アクション: 1tick1アクション制限 → 複数アクション実行可能

## 互換性

v3以前との互換性は一切不要。プログラム形式、セーブデータ等すべて刷新する。
