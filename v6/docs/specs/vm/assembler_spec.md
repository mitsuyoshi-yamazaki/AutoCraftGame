# アセンブラ仕様書 — v5

本VMのアセンブリ言語と、それをバイナリ（16bitワード列）に変換するアセンブラの仕様。

## 1. ソースファイル形式

- テキストファイル（UTF-8）
- 拡張子: `.asm`
- 1行に1命令、またはラベル定義、またはディレクティブ
- `;` 以降はコメント（行末まで）
- 空行は無視

## 2. 構文

### 2-1. ラベル

```
label_name:          ; ラベル定義（アドレスを記録）
    JMP label_name   ; ラベル参照（アドレスに解決）
```

- ラベル名: `[a-zA-Z_][a-zA-Z0-9_]*`
- ラベルは定義された位置のアドレス（ワード単位）を表す
- 前方参照可能（定義前に参照できる）

### 2-2. 命令

```
    ADD r1, r2, r3       ; Format R
    ADDI r1, r2, 5       ; Format I（即値）
    LI r1, 0x1000        ; Format W（16bit即値、2ワード）
    BEQ r1, r2, label    ; Format B（短分岐、4bitオフセット）
    BEQL r1, r2, label   ; 長分岐（2ワード、16bitアドレス）
    JMP label             ; 絶対ジャンプ（2ワード）
```

### 2-3. レジスタ名

| 名前 | レジスタ | エイリアス |
|------|---------|-----------|
| r0 | ゼロレジスタ | zero |
| r1 | 汎用 | |
| r2 | 汎用 | |
| r3 | 汎用 | |
| r4 | 汎用 | |
| r5 | 汎用 | |
| r6 | 汎用 | |
| r7 | スタックポインタ（慣例） | sp |

### 2-4. 数値リテラル

| 形式 | 例 |
|------|-----|
| 10進数 | `42`, `-8` |
| 16進数 | `0x1000`, `0xFF` |
| 2進数 | `0b1010` |

負数は符号付き即値（ADDI等）でのみ有効。

### 2-5. エイリアス命令

アセンブラが展開するエイリアス:

| エイリアス | 展開先 |
|-----------|--------|
| `MOV rd, rs` | `ADD rd, rs, r0` |
| `NOP` | `ADD r0, r0, r0` |
| `LI rd, imm16` | 2ワード命令 |
| `CALL rs` | `JALR r6, rs`（r6にリターンアドレス） |
| `RET` | `JALR r0, r6`（r6のアドレスに戻る。戻り値は破棄） |

### 2-6. 擬似命令

| 擬似命令 | 動作 |
|---------|------|
| `LA rd, label` | `LI rd, label_address`（ラベルのアドレスをロード） |

## 3. ディレクティブ

### 3-1. .word

```
.word 0x1234           ; 1ワードのデータを配置
.word 0x1234, 0x5678   ; 複数ワードのデータを配置
```

### 3-2. .zero

```
.zero 10               ; 0を10ワード分配置
```

### 3-3. .equ

```
.equ SENSOR_BASE, 0x6000    ; 定数定義
    LI r1, SENSOR_BASE       ; 定数を参照
```

### 3-4. .org

```
.org 0x0100            ; 出力アドレスを指定位置に設定（間は0埋め）
```

### 3-5. .include

```
.include "io_defs.asm"    ; 別ファイルの内容を挿入
```

## 4. 短分岐のオフセット解決

短分岐命令（BEQ, BNE, BLT, BGE）のラベル参照:

1. ラベルの絶対アドレスを算出
2. オフセット = ラベルアドレス - 現在の命令アドレス
3. オフセットが -8 ～ +7 の範囲内 → 短分岐として出力
4. 範囲外 → **エラー**（長分岐 BEQL/BNEL/BLTL/BGEL を使用するよう指示）

アセンブラは自動的に短分岐を長分岐に変換しない。プログラマが明示的に選択する。

## 5. 出力形式

### 5-1. バイナリ形式

16bitワードの配列。各ワードはリトルエンディアンで格納。

ファイル拡張子: `.bin`

### 5-2. 16進テキスト形式

1行に1ワード、16進4桁で表記。

```
0000
1234
5678
ABCD
```

ファイル拡張子: `.hex`

### 5-3. プログラム定義ファイル

初期キャラクターのプログラムとして読み込む際のJSON形式:

```json
{
  "name": "Replicator",
  "components": ["Frame", "Actuator", "Harvester", "Charger", "Assembler", "Processor", "Sensor", "MemoryCore"],
  "program": [0, 4660, 22136, 43981]
}
```

- `name`: 種族名（species）
- `components`: 初期コンポーネント構成
- `program`: 16bitワード列（10進数）

## 6. 標準ヘッダファイル

アセンブラ用に以下の標準定義ファイルを提供する:

### io_defs.asm

I/Oアドレスの定数定義:

```asm
; グローバル領域
.equ IO_ENERGY,       0x0000
.equ IO_DURABILITY,   0x0001
.equ IO_POS_X,        0x0002
.equ IO_POS_Y,        0x0003
.equ IO_VEL_X,        0x0004
.equ IO_VEL_Y,        0x0005
.equ IO_TICK,         0x0006

; Actuator[0]
.equ ACT0_STATUS,     0x1000
.equ ACT0_CMD,        0x1001
.equ ACT0_DIR,        0x1002

; Sensor[0]
.equ SEN0_STATUS,     0x6000
.equ SEN0_CMD,        0x6001
.equ SEN0_FILTER,     0x6002
.equ SEN0_COUNT,      0x6002  ; result (after command)
.equ SEN0_INDEX,      0x6003
.equ SEN0_E_TYPE,     0x6004
.equ SEN0_E_ANGLE,    0x6005
.equ SEN0_E_DIST,     0x6006
.equ SEN0_REG_CMD,    0x6007
.equ SEN0_REG_ID,     0x6008

; ... 他のコンポーネントも同様に定義
```

具体的なアドレス値は実装時に確定する。

## 7. エラー処理

アセンブラは以下のエラーを検出して報告する:

| エラー | 説明 |
|--------|------|
| 未定義ラベル | 参照されたラベルが定義されていない |
| 重複ラベル | 同名のラベルが複数定義されている |
| 短分岐範囲外 | BEQ等のオフセットが±7を超える |
| 不正なレジスタ名 | r0-r7以外のレジスタ指定 |
| 即値範囲外 | Format Iの即値が4bit範囲を超える |
| 不正な命令 | 定義されていない命令名 |
