# GUI 要件定義 — v5

## 目的

CLIベースの連続空間シミュレーションを2Dビジュアルで表示し、人間がオブジェクトの移動、衝突、イベントの発生をリアルタイムに把握できるようにする。

## 機能要件

### FR-1: 2D連続空間マップ表示

- ワールド（width × height の連続矩形領域）をCanvas上に描画する
- ワールド境界（壁）を視覚的に表示する
- ResourceNode（OreNode / CrystalNode）を角丸矩形で描画し、色で種別を区別する
  - remaining量に応じて濃淡を変える（残量が少ないほど薄い）
- EnergyNodeをダイヤモンド形で描画する（stored量に応じて濃淡を変える）
- Remains（残骸）を破断円弧で描画する
- キャラクターを円で描画する（アクティブ / 非アクティブを色で区別）
- 全オブジェクトの衝突半径を視覚的に反映する（オブジェクトの描画サイズ ≈ 半径に基づく）
- キャラクターの速度・加速度ベクトルの描画は行わない
- ズーム・パン操作でワールドの任意の領域を拡大・縮小・スクロールできる
- ズームアウト時、画面上のピクセルサイズが小さいオブジェクトは簡略描画（LOD）に切り替わる

### FR-2: オブジェクト選択と情報表示

- マップ上のオブジェクトをクリックすると選択状態となり、詳細パネルに情報を表示する
- **選択可能な対象**: Character, ResourceNode, EnergyNode, Remains, Ground（地面セル）
- 選択中のオブジェクトは黄色の枠で強調表示される
  - Character: 円形の選択リング
  - ResourceNode / EnergyNode / Remains: 円形の選択リング
  - Ground: 1×1セルの矩形枠
- 同じオブジェクトを再クリックすると選択解除される
- 何もないマップ上の地面をクリックすると、その位置のGroundGridセルが選択される
- 選択中のオブジェクトが消滅した場合（Character死亡、Remains吸収等）、選択は自動解除される
- **Character詳細（SelectedPanel）**: ID, active/inactive, 種族名, Age, 位置, 質量, 耐久値/最大耐久値, エネルギー, 前tickの予約アクション一覧（複数可）, **CheckpointHit（直近tickでCHECKPOINT命令が実行されたかの真偽値）**, コンポーネント一覧, インベントリ
- **Character VM状態（VMPanel）**: SelectedPanelの下に表示。キャラクター選択時のみ表示される
  - PC, VMレジスタ r0-r7, メモリサイズ, VM Active
  - 前tickの予約アクション一覧（SelectedPanelと同内容）
  - 失敗アクション一覧: 失敗したアクションのop名と失敗理由（ActionFailureReason）を表示
- **メモリ破損操作（CorruptButton）**: キャラクター選択時、SelectedContent 内に「破損: Nワード」ボタンを表示する
  - CorruptCountInput で破損ワード数を指定（デフォルト 1）
  - クリック時、選択中キャラクターのメモリ全域からランダムなN個のワードを別のランダム値に変更する
  - プログラム破損に対するロバスト性の評価用
- **ResourceNode詳細**: type, 位置, remaining, 生成tick
- **EnergyNode詳細**: 位置, stored/maxStored, productionRate, 生成tick
- **Remains詳細**: 位置, 吸収までの残りtick数, コンポーネント一覧, インベントリ
- **Ground詳細**: セル座標 (cellX, cellY), 吸収済みOre量, 吸収済みCrystal量

### FR-3: イベントログ

- character_spawned / character_died イベントをリアルタイムにログ表示する
- 各イベントにtick番号を付与する
- 誕生ログ: `[tick N] parentId spawned childId (species)` — 緑色
- 死亡ログ: `[tick N] charId (species) died` — 赤色
- 絶滅ログ: 同一tick内で最後の個体が死亡した種族について、`[tick N] *** species is now EXTINCT ***` を表示 — オレンジ色太字
  - 同一tick内で同種族の絶滅は1回のみ記録（重複排除）
- スクロール可能な領域に表示し、新しいイベントが追加されると自動スクロールする

### FR-4: シミュレーション速度制御

- tick/s（1秒あたりのtick数）を設定できる
- UI上の ◀ / ▶ ボタンで1刻みで変更する
- 範囲: 1〜60 tick/s
- デフォルト: 5 tick/s

### FR-5: 一時停止 / 再開 / ステップ実行

- Play/Pause ボタンクリックで一時停止 / 再開を切り替える
- スペースキーでもトグルできる
- Step ボタン: 一時停止中のみ有効。1tick分だけ状態を進める
  - 実行後もシミュレーションは一時停止状態を維持する
- 一時停止中もズーム、パン、オブジェクト選択/選択解除は動作する

### FR-6: 統計情報表示

- 現在のtick番号（コントロールバーに表示）
- 生存キャラクター数
- 累計誕生数 / 死亡数
- 残存ResourceNode数
- EnergyNode総stored量
- 残骸数
- 種族ごとの個体数（character.speciesでグループ化、個体数降順）
  - 種族名クリックでその種族のキャラクターを順に選択・自動パン
- アクション予約数（tickあたりの全キャラクターの予約アクション総数）

### FR-7: ズーム・パン操作

- **ズーム**: マウスホイールでズームイン・ズームアウト。ズーム中心はマウスカーソル位置
- **パン**: マウスドラッグでワールドの表示領域をスクロールする
- **初期表示**: ワールド全体が画面内に収まるズームレベルで開始
- **Fit**: ボタンクリックでワールド全体表示にリセット
- **Auto-pan**: 画面外のオブジェクトを選択した際（種族リスト経由等）、選択対象が画面中央に来るようパン
  - 既に画面内に表示されている場合はパンしない
- **LOD（簡略描画）**: ズームアウト時、描画オブジェクトの画面上のピクセルサイズが一定閾値以下になった場合、簡略描画に切り替える
  - ResourceNode: 小さな角丸矩形（OreNode/CrystalNode色、remaining比率で透明度変化）
  - EnergyNode: 小さなダイヤモンド形（金色、stored比率で透明度変化）
  - Remains: 小さな円（灰色）
  - Character: 黒丸の中にdurability残量を示す赤丸を描画

### FR-8: セーブ / ロード

- **Save**: 現在のゲーム状態をJSONファイルとしてダウンロードする
  - ファイル名: `{sessionStartedAt}[_{resumedAt}]_tick{N}.json`
  - 保存内容: バージョン, セッション開始日時, ゲームパラメータ, World状態, 統計, 直近イベント
- **Load**: JSONファイルを読み込みゲーム状態を復元する
  - メジャー・マイナーバージョンが一致しない場合はエラー表示
  - ロード後はシミュレーション一時停止状態で開始
  - イベントログは保存された直近イベントから復元

### FR-9: リセット

- Reset ボタンでランダムシードで新しいゲームを開始する
- シミュレーションは一時停止状態で開始する
- イベントログはクリアされる

### FR-10: バージョン表示

- コントロールバー右端にゲームバージョン（`vX.Y.Z` 形式）を表示する

## 非機能要件

- ブラウザ上で動作する（サーバー不要、Vite dev serverのみ）
- 既存のゲームロジック（src/）をUI目的で変更しない（ただしActionRecordのreason追加のようにゲーム本体としても有用な変更は許容する）
- pixi.js v8を描画エンジンとして使用する
