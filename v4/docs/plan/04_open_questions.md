## 未決定: 優先度高（最小スコープに直結）

### Q5. 1tickあたりの実行量

- 固定命令数 / コンポーネント依存（Processorスペック） / 他
- 無限ループ防止策
- ブロックWRITEにより自己複製のループ問題は解消されたが、通常のプログラム実行量の設定は必要

### Q7. メモリサイズとコンポーネントの関係

- MemoryCore 1個あたりのワード数
- コスト（基礎代謝）とのバランス

### Q8. ASSEMBLEのランタイム引数の指定方法

- I/Oスロット上のどこから、どのような形式でcomponentsリストを読み取るか

### Q15. SENSEの結果件数上限

- 固定 / Sensor性能依存 / メモリ依存 / 他
- バッファサイズに直結

### Q16. I/Oスロットの種別ごとの具体レイアウト

- 各コンポーネント種別のスロット内フィールド定義
- SLOT_SIZEの具体値
- Processorスロット: target_id, write_src_addr, write_dst_addr, write_length, command 等
- Assemblerスロット: componentsリストの格納形式
- Sensorスロット: 結果バッファ、登録操作フィールド
