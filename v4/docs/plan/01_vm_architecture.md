# v4 計画: VMアーキテクチャ

## ワードサイズと値の型

- **16bit符号なし整数**（0-65535）
- 8bitでは角度(0-359)、エネルギー(数千)、メモリアドレス等が収まらないため16bitとした
- 符号付き整数が必要な場合は高級言語/コンパイラ側で対応する
- **浮動小数点は不要** — ゲームシステム上の浮動小数値はVM I/Oにおいて整数に丸める

### 浮動小数→整数丸めについて

- エネルギー: v3実装でもすべて整数演算。問題なし
- 角度: 整数度(0-359)。最大0.5度の誤差、実用上問題なし
- 座標: 整数丸めの具体方針は未決定

## メモリモデル

### ノイマン型統一アドレス空間

プログラム（命令列）とデータが同一アドレス空間に存在する。

- メモリとして読み書きしていた領域にプログラムカウンタを移動させれば、その内容がプログラムとして解釈・実行される
- 自己プログラム読み取りは通常のload命令で実現できる
- 自己書き換えプログラムが原理的に可能

### メモリサイズ

- コンポーネント依存とする（例: MemoryCore 1個 = Nワード）
- 巨大なメモリ使用を可能にしつつ、コンポーネントコスト（基礎代謝等）でバランスを取る
- 具体的なサイズとコンポーネントの関係は未決定（Q7）

### アドレス空間

- 16bitアドレス = 最大65536ワード（128KB相当）

## 実行モデル

### プログラムカウンタの持続

tick間でPCを保持する。

- 前tickの続きから実行できる
- 複数tickにまたがる処理が記述可能
- HALT命令でtickの実行を終了する
- 将来的にはProcessorのスペックによりtickあたりの実行命令数を増減させることも可能

### tickあたりの実行量

未決定（Q5）。無限ループ防止のため何らかの上限が必要。

### NOOP

不要。プログラムがアクションを予約しなければNOOP相当。

## レジスタ

| レジスタ | 幅 | 用途 |
|---------|-----|------|
| r0 | 16bit | ゼロレジスタ（常に0、書き込みは破棄） |
| r1-r6 | 16bit | 汎用 |
| r7 | 16bit | 慣例上スタックポインタ（ハードウェアは強制しない） |
| PC | 16bit | プログラムカウンタ（tick間で保持） |

## 命令セット

### 命令フォーマット

1ワード（16bit）固定長を基本とし、即値が必要な場合は次の1ワードを使う。

**Format R（レジスタ間演算）:**
```
15       10 9   7 6   4 3   1 0
[opcode:6][rd:3][rs1:3][rs2:3][x:1]
```

**Format I（短即値付き）:**
```
15       10 9   7 6   4 3      0
[opcode:6][rd:3][rs:3][imm:4]
```

**Format W（16bit即値付き、2ワード命令）:**
```
1ワード目: [opcode:6][rd:3][rs:3][x:4]
2ワード目: [imm16:16]
```

**Format B（分岐）:**
```
15       10 9   7 6   4 3      0
[opcode:6][rs1:3][rs2:3][offset:4]
```

6bitオペコード = 最大64命令。

### 命令一覧

**算術演算:**
| 命令 | 形式 | 動作 |
|------|------|------|
| ADD rd, rs1, rs2 | R | rd = rs1 + rs2（ラップ） |
| SUB rd, rs1, rs2 | R | rd = rs1 - rs2（ラップ） |
| MUL rd, rs1, rs2 | R | rd = (rs1 * rs2) の下位16bit |
| DIV rd, rs1, rs2 | R | rd = rs1 / rs2（0除算 → 0） |
| MOD rd, rs1, rs2 | R | rd = rs1 % rs2（0除算 → 0） |
| ADDI rd, rs, imm4 | I | rd = rs + imm4 |

**論理演算:**
| 命令 | 形式 | 動作 |
|------|------|------|
| AND rd, rs1, rs2 | R | ビットAND |
| OR rd, rs1, rs2 | R | ビットOR |
| XOR rd, rs1, rs2 | R | ビットXOR |
| SHL rd, rs1, rs2 | R | 論理左シフト |
| SHR rd, rs1, rs2 | R | 論理右シフト |

**メモリ操作:**
| 命令 | 形式 | 動作 |
|------|------|------|
| LW rd, rs, imm4 | I | rd = mem[rs + imm4] |
| SW rs, rd, imm4 | I | mem[rd + imm4] = rs |
| LI rd, imm16 | W | rd = imm16（2ワード命令） |

**I/O操作:**
| 命令 | 形式 | 動作 |
|------|------|------|
| IN rd, rs | R | rd = io_read(rs) |
| OUT rs1, rs2 | R | io_write(rs1, rs2)  rs1=アドレス, rs2=値 |

**制御フロー:**
| 命令 | 形式 | 動作 |
|------|------|------|
| BEQ rs1, rs2, off4 | B | rs1 == rs2 → PC += off4 |
| BNE rs1, rs2, off4 | B | rs1 != rs2 → PC += off4 |
| BLT rs1, rs2, off4 | B | rs1 < rs2 → PC += off4（符号なし） |
| BGE rs1, rs2, off4 | B | rs1 >= rs2 → PC += off4（符号なし） |
| JMP imm16 | W | PC = imm16（2ワード命令） |
| JALR rd, rs | R | rd = PC+1, PC = rs |

**スタック操作:**
| 命令 | 形式 | 動作 |
|------|------|------|
| PUSH rs | I | r7 -= 1, mem[r7] = rs |
| POP rd | I | rd = mem[r7], r7 += 1 |

**特殊:**
| 命令 | 形式 | 動作 |
|------|------|------|
| HALT | - | このtickの実行を終了 |
| MOV rd, rs | - | ADD rd, rs, r0 のエイリアス |
| NOP | - | ADD r0, r0, r0 のエイリアス |

- 「人間が記述できること」は必須要件
- 高級言語 → コンパイラ → 命令列のツールチェインにより達成可能
- アセンブリ直書きも可能であるべき
