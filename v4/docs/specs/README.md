# v4 仕様 — 概要

## v4の目標

キャラクターのプログラムを変化可能にし、進化が創発するシミュレータを実現する。

## v3からの主な変更点

### プログラムモデルの刷新

v3の「条件→アクション」ルール列を廃止し、16bit VMによる汎用プログラムに置き換える。

- ノイマン型メモリモデル（プログラムとデータが同一空間）
- 自身のプログラムを通常のメモリ操作で読み書き可能
- I/O空間を介してゲーム世界と相互作用

### アクションモデルの変更

- 1tickあたり複数アクション実行可能（異なる種別同士）
- アクションは「予約→一括実行」方式
- WRITEはブロック書き込み（エネルギーコストは長さに比例）
- ASSEMBLEのコンポーネント構成をランタイムに決定
- 対象指定にローカルIDを使用（システムIDを隠蔽）

### コンポーネントの変更

- Registerコンポーネントを廃止（レジスタはVMに内蔵）
- MemoryCoreがVM用メモリを提供（1個あたり1024ワード）

### プログラムのDSL廃止

v3のプログラム仕様（Rule, Condition, Action型、set_registers、FnValue等）は全て廃止。
キャラクターの行動はVM命令列によって記述される。

## v3から変更なしの仕様

以下はv3の仕様をそのまま踏襲する:

- 物理モデル（力、摩擦、衝突、質量、速度、位置）
- 距離判定（ユークリッド距離、INTERACT_RANGE）
- HARVEST, RECHARGE の基本動作
- PROCESS, CRAFT のレシピ
- REPAIR の動作
- DISASSEMBLE の流出テーブル
- 死亡と残骸の生成
- GroundGrid と資源再生
- 加齢代謝
- 耐久値減衰
- EnergyNode の生産
- ワールド境界（壁）

## 互換性

v3以前との互換性は一切不要。プログラム形式、セーブデータ等すべて刷新する。
