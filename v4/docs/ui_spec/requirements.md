# GUI 要件定義 — v4

v3からの変更箇所のみ記載。記載のない項目はv3仕様（v3/docs/ui_spec/requirements.md）に従う。

## 変更のある要件

### FR-2: オブジェクト選択と情報表示

キャラクター選択時の表示項目を変更:

| 項目 | v3 | v4 |
|------|----|----|
| Program | 表示（プログラム名） | 廃止 |
| Species | character.species | 同じ |
| Active/Inactive | program !== null | character.active |
| Registers | レジスタ値一覧 | VMレジスタ r0-r7 の値 |
| PC | なし | 現在のプログラムカウンタ |
| Memory Size | なし | メモリワード数 |
| Action | 前tickの実行アクション | 前tickの予約アクション一覧（複数可） |

### FR-6: 統計表示

追加表示項目:
- アクション予約数（tickあたりの全キャラクターの予約アクション総数）

## 変更のない要件

以下はv3と同じ:
- FR-1: 2D連続空間マップ表示
- FR-3: イベントログ
- FR-4: シミュレーション速度制御
- FR-5: 一時停止/再開/ステップ
- FR-7: ズーム/パン操作
- FR-8: セーブ/ロード
- FR-9: リセット
- FR-10: バージョン表示
