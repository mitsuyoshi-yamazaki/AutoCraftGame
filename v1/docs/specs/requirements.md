# 要件定義

本ディレクトリの仕様は、以下の要件を満たすものとして策定された。

---

## プロジェクトの目的

自己複製可能な自律キャラクターが構築できるかを検証するプロトタイプの作成。

## コンセプト要件

- 通常のクラフトゲームとの違い: プレイヤーがキャラクターを直接操作するのではなく、キャラクターが自律動作する
- キャラクターが自身と同じ仕様のキャラクターをクラフトすれば自己増殖となる
- 自己修復能力を超える損傷を負えば死ぬ

## 自律動作の要件

通常のクラフトゲームでプレイヤーが行うことの一切を自動化する:

- 素材の収集
- 素材の加工
- クラフト（組み立て）
- それらの行動のプランニングと実行

## キャラクター設計の要件

- 初期キャラクターは人間のプレイヤーが仕様を決めてゲームへ放つ
- 人間の能力でプログラムできる仕組みが必要
- キャラクターの内部処理（思考・意思決定）の仕組みが設計されていること

## プロトタイプとしての要件

- 正常系が動作すればよい
- 拡張性は不要
- ClaudeCode主体で実装し、実行と動作確認までエージェントが完結する形とする
- 仕様更新のたびにプロトタイプを作り直すため、生成方法をある程度確立する

## 検証事項

1. Programの組立指示でBody構成を自由に決定できるか
2. MemoryCoreのデータコピーでProgramが正しく伝達されるか
3. Program内の組立指示の変更で進化（異なる構成の娘）が実現できるか
